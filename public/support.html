Before requesting help / 反馈前

  • Open Settings and export an Excel backup before clearing data or reinstalling. / 清除数据或重装前，请先在设置中导出 Excel 备份。
  • Include the Fortuna version, iOS version, steps to reproduce, and a screenshot with sensitive amounts hidden. / 请提供 Fortuna 版本、iOS 版本、复现步骤，并先隐藏截图中的敏感金额。
  • Never post real account numbers, transaction records, backup files, or other sensitive financial data. / 请勿公开真实账号、交易记录、备份文件或其他敏感财务信息。

Contact / 联系

Open a GitHub support issue / 提交 GitHub 问题

Fortuna does not operate a support database or user account system. Information you choose to post on GitHub is handled by GitHub under its own terms. / Fortuna 不运营客服数据库或用户账号系统；你主动发布到 GitHub 的信息由 GitHub 按其规则处理。
