## Fortuna 1.8.2

- 从「设置 → 恢复数据」选择备份后，如果已有账本数据，会明确询问「已有数据，是否全部覆盖？」。
- 选择「是，全部覆盖并导入」会在一次事务中替换全部账本、资产配置、设置和缓存汇率，清除备份中没有的内容。选择「否」不会改动数据。相同备份可重复恢复，不会叠加记录。
- 旧备份缺少的设置使用默认值；恢复时不会混入旧账本的配置和缓存。校验或写入失败会保持当前数据完整。
- 导出读取同一时点的完整数据，避免同时写入时生成不一致、无法恢复的备份。
- 恢复直接读取文件字节，并保留具体失败原因与错误详情，区分文件读取、备份内容校验和本地数据库问题。

### 更新

在 App「设置 → 检查更新」下载并安装，或下载下方 `Fortuna-1.8.2-release.apk` 直接覆盖安装。无需卸载现有 App。

包名 `com.fortuna.wealthtracker` 和正式签名保持一致。版本号为 1.8.2，Android versionCode 为 18。

### 验证范围

220 项自动测试、代码检查和构建通过；恢复测试覆盖相同 ID、额外旧数据、重复导入、完整覆盖、旧备份、并发导出和写入失败回滚。特定手机的文件提供程序与实际覆盖安装仍需设备验证。
