## Fortuna 3.5.0

自 `2.0.0` 以来的阶段性稳定整合版本：清理此前频繁跳号与试验性修补版本，重整为扎实的版本序列（后续严格遵循标准语义化版本：大改升主版本、功能迭代升次版本、修复升末位）。

### 核心更新
- **计划页层级与红利整合**：计划卡片统一按「母分类实际占比 → 策略备注 → 子分类占比 → 子分类下计划与仓位阶梯」展示；内置「阶梯网格」「个股/基金卡片」「红利价值组合」「基础配额+备注」四种管理模式及全局活钱蓄水池对账。
- **红利基金与红利股内嵌计划页**：红利卡片内直接管理「红利基金」与「红利股」两个子分类区块（子分类 `role` 随 Excel/JSON 备份保留），基金按指数股息率换算买入档位价格，红利股内联展开四买四卖仓位阶梯；红利工作台精简保留 AI 问答与选股计划，预算自动随对应子分类同步。
- **经典红利定价体系**：以已核验最近分红批次与最近年报每股收益封顶为统一定价基数；支持 20%/10%/0% 税率、手动价格模式、对称市场偏离提示与安全清理标的。
- **组合净值、现金倒减与滚动记忆**：投资组合支持现金倒减与按命名组合统计单位净值，支持股票/ETF/黄金到价提醒，并在页签切换、账户详情与红利工作台往返时保持滚动位置。

### 安装说明
- 继续沿用既有正式签名证书与包名（`versionCode 59`），可保留全部本地数据直接覆盖安装。
- 若手机当前已安装此前更高显示版本号（如 `8.x`～`11.x`）的 APK，请本次通过浏览器下载下方 `Fortuna-3.5.0-release.apk` 手动覆盖安装一次；安装完成后，后续版本的 App 内自动检查更新将恢复正常。
