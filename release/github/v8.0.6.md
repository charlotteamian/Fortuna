## Fortuna 8.0.6

- 修复打开“选股与计划”时，旧检查结果与新定价数据混用引起的白屏。
- 数据不完整或检查尚未同步时保留补录提示，不展示可确认的新网格；已有计划不改写。
- 红利基金卡片直接展示三档买入档位和网格价格，移除“依据与数据”长文。
- 保留现价、计划金额、卖出安排；第1档沿用原触发价，第2、3档按前档90%、95%展示网格参考。

### 安装与更新

下载 `Fortuna-8.0.6-release.apk` 覆盖安装，或在 App 设置中检查更新。沿用既有包名和长期正式签名，Android versionCode 50，iOS 元数据 build 50。

### 验证

发布前898项自动化测试、代码规范检查、网页构建及iOS资源一致性检查通过。隔离浏览器覆盖已有选股计划、定价展开、基金首页与管理卡片、金额隐藏及8组宽度/字号/主题组合。正式APK由GitHub Actions构建并校验签名身份，下载包签名、版本、网页资源和更新识别均已核对。隔离模拟器从8.0.5覆盖升级通过，测试账户、金额和快照保留，选股与计划及底部计划页正常。未进行实体手机验证。
