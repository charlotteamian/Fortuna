## Fortuna 8.0.4

- 行情口径优化：改为交易日口径（当天或最近一个交易日跳过周末，36 小时内新抓取的报价均算有效，法定节假日覆盖），避免周末收盘价被误标待核对。
- 红利基金卡片布局：统一两栏字号（clamp 自适应），防止净值与金额断行折行。
- 计划页面排版：优化“计划总额 / 总资产”对齐基线，使两栏底部一致。
- 页面空行修复：调整全局 `.app-content` 底部留白，消除底部多余大空白。
- 结构化数据核验基准：更新分红定价方法文档与研究服务，以结构化分红数据为核验基准。

### 安装与更新

下载 `Fortuna-8.0.4-release.apk` 覆盖安装，沿用既有包名和长期正式签名。Android versionCode 48，iOS 元数据 build 48。
