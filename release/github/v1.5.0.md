## 中文

Fortuna 1.5.0 新增证券截图识别和 Excel 持仓导入，并支持批量修改持仓股数与价格。

- 在股票/ETF 资产详情或「添加持仓」中进入导入。上传券商截图后，预览并核对股票/ETF 名称、代码、总持仓股数、当前报价与成本；截图中明确的买卖成交也可补录日期、方向、股数和成交价。支持追加多张截图。
- 视觉 API 提供通义千问、智谱 GLM、Kimi、豆包预设，以及 OpenAI 兼容、Gemini、Anthropic 和自定义地址。模型和地址均可修改；豆包需填写已开通的视觉模型或接入点 ID。在「设置 → 视觉 API 配置」首次配置后保存在本机，后续可直接上传截图；导入页可跳转设置，返回后保留预览。
- 导入仅更新当前证券资产，按代码与市场匹配；保留已有交易和计划关联，不清空截图中未出现的持仓，不修改现金或其他资产。确认后尝试刷新行情。
- 股数修改保存为持仓校准。真实买卖与最终持仓分开处理，避免重复计算股数；成交去重，整批校验失败会回滚。缺少历史持仓的卖出、成本口径不明、同日成交顺序冲突需先核对。
- Excel 模板带出现有持仓，也支持 XLSX/XLS/CSV 和常见中英文表头。删掉某一行表示不更新该持仓，清仓需明确填写股数 0。

截图仅在发起识别时发送给选定的 API 服务商，密钥不进入账本备份或自动快照，API 费用与数据处理遵循服务商规则。兼容范围是所列三种请求协议；需要图片输入能力。

验证：158 项自动化测试、Lint、生产构建与浏览器模拟 API 流程通过，覆盖资产隔离、重复导入、持仓校准、交易记录与 320px 布局。尚未使用真实付费模型验证各券商截图准确率，未进行手机安装复测。

更新：在「设置 → 关于 → 检查更新」下载，或安装附件 `Fortuna-1.5.0-release.apk`。正式 APK 使用既有长期签名，Android versionCode 升至 10。新增持仓校准需要 1.5.0 或更新版本读取，请勿将含校准记录的新备份恢复到旧版。

## English

Fortuna 1.5.0 adds broker screenshot recognition, Excel holding imports, and bulk editing of quantities and prices.

- Upload screenshots from a stock/ETF asset or Add Holding, then review and edit names, symbols, total quantities, quotes and costs before saving. Confirmed executions can also supply dates, buy/sell directions, quantities and execution prices. Multiple screenshots can be added.
- Vision API presets include Qwen, Zhipu GLM, Kimi and Doubao, alongside OpenAI-compatible Chat Completions, Gemini and Anthropic. URLs and models remain editable. Doubao requires an enabled vision model or endpoint ID. Configuration is managed in Settings → Vision API Configuration and reused for later imports. Opening settings from an import retains the preview when you return.
- Imports affect only the current securities asset. Matching uses symbol and market, retaining existing transactions and plan links. Omitted holdings, cash and other assets remain intact; market quotes are refreshed when available.
- Quantity changes use position adjustments. Actual executions and final positions are handled separately to prevent double counting, with duplicate detection and atomic validation. Missing opening history for sells and ambiguous same-day ordering require review.
- The Excel template contains existing holdings and accepts XLSX/XLS/CSV with common English and Chinese headers. Omitted rows mean no update; closing a position requires an explicit zero quantity.

Screenshots are sent to the configured API only when recognition is requested. Credentials are excluded from ledger backups and automatic snapshots. Provider fees and data policies apply. Compatibility covers the three supported request protocols and requires a vision model.

Validation: 158 automated tests, lint, production build and browser flows with a mocked API passed, including scope isolation, duplicate imports, position adjustments, transaction history and a 320px viewport. Real paid-model recognition accuracy and physical-device installation have not been tested.

Update through Settings → About → Check for updates, or download `Fortuna-1.5.0-release.apk`. The release retains the permanent signing identity and raises the Android version code to 10. Backups containing position adjustments require version 1.5.0 or later; do not restore them into an older version.
