# Fortuna 3.0.1

- 股票详情的买入、卖出入口移到交易记录上方，长记录列表也能快速录入。
- 选股检查按股票保留结果，单股复核不会清空其他公司；每只股票可独立收起，并保留检查日期和折叠状态。
- 复核将已识别风险与待补充证据分开展示。经营、分红和走势作为提示，不再自动建议或写入暂停加仓。
- 买入判断直接比较已保存的网格价格，安全边际独立参考，不再重复增加恢复门槛。新价格计划保留原手动加仓状态；恢复已有暂停仍需本人预览确认。
- 红利首页和计划管理均显示档位编号、已触发颜色与文字，以及当前最深触发档位；报价不可用时显示待更新。
