## Fortuna 8.0.5

- 修复组合净值漏算多持仓、同日多笔重复计算、期权乘数及区间收益基准。
- 最新分红批次金额缺失时不再使用旧年度金额生成网格。
- 修复股息率参数保存和旧定价缓存兼容；修改档位后提示旧网格参数已变化。
- 股票与基金采用一致行情规则：交易日要求当日报价，仅非交易日接受36小时内抓取的有效报价。
- 一般关注不再限制买入；分红台账显示实际计入状态，检查记录使用实际结构化来源，不再补查巨潮。
- 修正档位说明和净值空状态提示；保持一套价格展示，在卡片内确认写入。

### 安装与更新

下载 `Fortuna-8.0.5-release.apk` 覆盖安装。沿用既有包名和长期正式签名，Android versionCode 49，iOS 元数据 build 49。
