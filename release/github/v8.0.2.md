## Fortuna 8.0.2

- 资产再平衡自动出资优先级瀑布（Funding Waterfall）：欠配标的补仓时优先使用闲置现金，其次减持超配标的，最后由低到高赎回低优先级标的，清晰规划调仓资金路径。
- 资产组合单位净值与最大回撤（Unit NAV）：引入时间加权单位净值算法，剔除外部本金充提与现金流干扰，真实衡量多账户投资表现。
- 强周期股分红平滑机制：针对煤炭、矿业、石油、有色、航运等强周期行业，若最新年度分红偏离近 3 年均值超过 30%，自动按近 3 年平均分红平滑估算，防范周期高点虚高股息率误导定价。
- 完善分红周期合并逻辑：强化中期分红（H1）与年度分红（FY）的过渡期保护，避免首次派发中期分红时产生双重计算。
- 页面视觉优化与响应式适配：重构账户详情、标的资产总览、配置计划与记录流水的排版、间距与数据表格，提升小屏及大字号下的浏览与操作体验。
- 859 项全量自动化测试、ESLint 规范与跨端构建校验通过。
