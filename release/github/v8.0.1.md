## Fortuna 8.0.1

- 红利基金首页改为“今日操作”：直接显示达到买入条件、到卖出参考价、等待或更新数据；旧版检查批次面板移出首页。关联持仓和配置目标分别展示。
- 选股与计划重新整理按钮、股票标题、报价、目标和定价表格，修复小屏拥挤、断行、空白和裸翻译键；支持放大字体。
- 增加“自动补齐资料并检查”和单股补齐入口。同日解析失败的公告可重试；自动继续核验后续公告，成功证据及原日期继续复用。
- 定价展示“已实施分红 → 扣税一次 → 固定股息率”的三步说明。价格条件、经营观察和历史资料缺口分开呈现，详细观察与来源按需展开，多个特别分红事件各自的来源与日期完整保留。
- 证据不足时保留旧计划，移除未经核验的备用价格及直接应用按钮。新价继续先预览、再确认，同时保存四买四卖。
- 增加“一键重新分配预算”，预览确认后均分全部股票，包括原 0% 和隐藏股票。删除并再分配时，释放比例也包含原 0% 股票；基金预算独立。
- 均分和按比例分配的预算预览若遇到总预算、名单或权重变化，会拒绝过期确认；重新分配不改变实际持仓、价格网格或手动暂停状态。

### 安装与更新

下载 `Fortuna-8.0.1-release.apk` 覆盖安装，沿用既有包名和长期正式签名。Android versionCode 45，iOS 元数据 build 45。

自动补齐不代表所有外部公告都能解析成功；未确认的来源和真实冲突继续保留具体缺口，不编造已通过结果。
