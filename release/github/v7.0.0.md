## Fortuna 7.0.0

- 红利选股与计划管理合并为“选股与计划”。每只股票可直接修改观察 / 核心 / 隐藏状态、暂停买入、编辑预算或删除；有持仓的股票继续保留删除保护。
- 选股卡片先展示现价、买卖目标、分配金额和具体未达标原因，完整检查与定价依据默认收起。
- 批量导入移入选股页面；行情与分红刷新、红利助手入口移到红利页面上方。
- 红利基金突出当前价格、买入和卖出计划、金额分配，详细数据按需展开。
- 切出 App 再返回时保留助手页面、页签、滚动位置和未发送问题；聊天输入区和发送按钮适配小屏。
- 资产首页可调整分类与账户顺序并保存；证券和黄金监控统一放在顶部。

### 安装与更新

下载下方 `Fortuna-7.0.0-release.apk` 覆盖安装。沿用原有包名和正式签名，Android versionCode 为 43。
