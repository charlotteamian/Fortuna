## 中文

Fortuna 1.3.2 简化了配置计划页。

- 每类资产直接对照计划金额／占比、当前金额／占比，显示进度和距计划的差额。
- 想买的标的直接写名称、代码或备注；无需先建立持仓，也无需给每个标的分配比例。
- 编辑按钮直接可见；配比图、市场／账户／持仓细分设置按需展开，原有分项与关联继续保留和编辑。
- 可按比例或金额填写，并明确计划总额的计算基准。
- 新增标的备注支持 Excel 备份恢复和自动快照；按现有资产生成计划时整批保存，避免半完成和重复创建。

与 GitHub 正式版 1.3.0、1.3.1 使用相同的长期签名，可在「设置 → 关于 → 检查更新 → 下载并安装」覆盖更新，保留本地数据。系统可能要求允许 Fortuna 安装更新，允许后返回继续安装。

安装附件中的 `Fortuna-1.3.2-release.apk`。本次正式包不使用本地 debug 包的签名。

## English

Fortuna 1.3.2 simplifies allocation plans.

- Compare planned and actual amounts and percentages for each asset class, with progress and the remaining or excess amount.
- Record intended purchases without creating holdings or allocating percentages to individual targets.
- Use visible edit actions and expandable allocation charts and advanced settings. Existing subcategories and product links remain editable.
- Enter a percentage or amount with a clearly stated plan base.
- Purchase notes survive Excel backup/restore and automatic snapshots. Initial plans are saved atomically.

This APK uses the same permanent release certificate as GitHub versions 1.3.0 and 1.3.1. Update in place through Settings → About → Check for updates → Download and install, retaining local records.
