## Fortuna 8.0.10

- 修复境内市场行情时间戳校验按 UTC 解析的问题，改为按上海时间（Asia/Shanghai，+08:00）往返校验，避免 00:00–07:59 早盘或盘前时间被误判为无效行情。
- 修复资产配置计划金额模式输入换算目标比例时未按分取整导致金额往返不一致的问题，并保留计划目标总额原始输入精度。
- 修复设置页汇率更新时间按 `t('zh') === '简体中文'` 判断本地化格式的问题，改为按当前已解析语言 `i18n.resolvedLanguage` 判断中文或英文显示。
- 修复红利每日检查测试中 `AbortSignal.timeout` 超时用例在 Node 事件循环下提前退出的稳定性问题。

Android 请下载下方 `Fortuna-8.0.10-release.apk` 覆盖安装，或在 App 设置中检查更新；继续沿用既有正式签名证书与包名（`versionCode 54`）。
