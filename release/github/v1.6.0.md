## Fortuna 1.6.0

- 已归档持仓显示完整名称，长名称可换行，卡片不再展示代码。
- 红利工作台顶部新增「直接持有红利股票 / 持有红利基金」策略选择，两种策略分别保留预算与标的。
- 基金策略可录入名称、可选代码、跟踪指数类型、占比与备注，直接查看计划金额；支持长期持有、7:3 股债年度再平衡和回调波段。
- 7:3 配置将总预算的 70% 分配给红利基金、30% 预留债券；基金占比以红利基金仓位为基准，合计最多 100%，允许保留待分配部分。
- 默认买入参考为前高回撤 10% 与指数股息率 5%，可修改阈值和条件组合。参考价格、指数股息率及日期可手动录入；过期或缺失数据不会触发当日条件提示。
- 基金计划、策略选择和参考数据支持 Excel / JSON 备份恢复及自动快照。计划金额不会增加实际资产余额。

### 更新

在 App「设置 → 检查更新」下载并安装新版，或下载下方 `Fortuna-1.6.0-release.apk` 覆盖安装。使用与之前版本一致的正式签名，版本号为 1.6.0，Android versionCode 为 12。

### 验证

179 项自动测试、ESLint、TypeScript 和生产构建通过。浏览器在 390px / 320px 验证基金录入、分配、占比上限、保存恢复及归档名称布局。基金参考条件可修改，提示依据手动录入的当日数据。

本次没有连接的实体 Android 设备，实体设备覆盖安装尚未验证。
