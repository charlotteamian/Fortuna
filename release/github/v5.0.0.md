## Fortuna 5.0.0

- 分红改为逐笔台账，东方财富记录与巨潮实施公告PDF核验；冲突和未核验批次不进入新网格。
- 半年分红使用最近两批，年度分红使用最近一批；预案单独展示，盈利与派息交叉校验偏离超过25%时提示口径待核实。
- 税率可选20%／10%／0%，默认10%；税前税后价格并列，买价向下、卖价向上取整到分。
- 已保存网格记录生成依据，基数变化、除息或参数变化只提醒重审，不自动改价；资料不足时明确按旧网格判断或无法判断。
- 历史价格范围与公告核验覆盖分开显示；ROE区分年报与季度年化，补充银行专项检查及具体缺口。
- 选股检查集中展示网格，只保留一个预览确认入口；股票和基金计划在红利首页同时展示，可直接生成今日操作建议。

下载下方正式签名APK安装。已有版本可覆盖升级；数据保留以设备实际安装验证为准。
