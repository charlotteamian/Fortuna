## 中文

Fortuna 1.3.1 是账户操作与页面排版优化版本。

- 首页不再在每项资产旁显示隐藏图标；长按资产或负债后，可直接选择隐藏、计入资产统计或不计入资产统计。
- 新建和编辑资产时，“计入资产统计”改成更紧凑清晰的开关排版。
- 设置页的“已隐藏资产/负债”改成单一入口，点开后集中查看和解除隐藏，不再拉长设置页。
- 修复解除隐藏后，当前已显示的金额会被自动切回隐藏状态的问题。
- 所有余额、金额、价格和盈亏数字改用与资产页一致的常规字体，不再使用细长的等宽字体。
- “检查更新”已精简并直接放入“设置 → 关于”，发现新版后可继续下载并安装。

本版本与 1.3.0 使用同一长期签名，可直接在 Fortuna 中检查并覆盖更新，无需卸载，也不会清除本地数据。

## English

Fortuna 1.3.1 refines account actions and Settings layout.

- Account hiding and total-inclusion controls now live in the account long-press menu, with no repeated hide icon beside every overview row.
- The Include in totals control uses a compact switch in create and edit forms.
- Hidden assets and liabilities are managed from one Settings button and a focused recovery sheet.
- Unhiding an account no longer resets the current amount-visibility state.
- Balances, amounts, prices, and P&L now use the app's regular asset-number typeface instead of the narrow monospace style.
- Check for updates now sits directly under Settings → About and continues into download and installation when a release is available.

This release uses the same permanent signing identity as 1.3.0, so it can update in place without uninstalling or clearing local data.
