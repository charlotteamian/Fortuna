## Fortuna 9.0.0

- 派息率超过 100%（所选最近批次现金高于最近年报每股收益）时，红利定价基数按 `min(已实施分红, 最近年报每股收益)` 封顶，卡片与台账显示已实施分红、盈利上限与封顶原因；缺少每股收益时提示「未能核对盈利」，最近年报亏损时不生成股息率价格。
- 红利首页与选股检查统一使用同一套已核验最近批次基数，删除公告预案、递推、行业基准表、0.5 元占位与周期平滑兜底；没有已核验基数时不生成网格价格，只显示已保存手工网格作为参考。
- 新增手动价格模式（低息成长股不适用固定股息率时由用户填写买卖价格），批量写入跳过手动价格标的；表单旁显示年线（250 日均线）、近一年高低点与现价分位作为技术参考线。
- 市场偏离提示对称化：现价高于最高卖档或低于最低买档 20% 以上都提示偏离，今日动作降级为「仅参考」。
- 不再自动内置 19 只预设红利股，只保留用户实际加入或关联持仓的股票；新增「清理股票」入口，用户勾选确认后删除，有持仓或手动股数的股票受保护。
- 恢复派息率超 100% 与自由现金流覆盖不足的可持续性提示；计算版本升至 6，已保存网格不自动覆盖，提示重新生成并由用户确认。

Android 请下载下方 `Fortuna-9.0.0-release.apk` 覆盖安装，或在 App 设置中检查更新；继续沿用既有正式签名证书与包名（`versionCode 55`）。
