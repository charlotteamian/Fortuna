# Fortuna 1.10.0

- AI 截图导入自动跳过新债、可转债申购及占位记录；正常上市债券持仓与真实成交仍可导入。全部跳过时显示原因，不写入账本。
- 红利助手支持本机历史聊天自动保存、恢复、新建与删除，保存失败可重试。聊天、选股与检查、选股原则分为三个页签，详细资料折叠展示。
- 行动分析加入个股日线、上证／沪深300／创业板指数和近期财务数据。发现下跌加速时先提出暂停加仓；计划调整先预览，再确认反写原网格页面。
- 选股原则可配置现金股息率、年度 ROE、营收／利润增长、负债、现金流、分红覆盖、连续分红及补充原则。支持默认候选池或输入代码筛选、加入观察列表、请 AI 解读。
- 检查计划中的股票并列出不符合原则的项目，确认后批量移除无持仓项目。手工、关联、其他账户和归档账户中的持仓受保护，删除时再次核对，未用预算保留。
- 缺失、失败和陈旧资料标为待核实。金融行业需专项核实；技术信号仅用于加仓节奏，不能单凭下跌否定长期持有逻辑。

财务分析使用带报告期、公告日和来源的结构化数据，并未下载财报全文、审计意见或实时新闻。候选筛选范围限于页面列明的候选池／代码。历史聊天保存在本机，不包含在资产账本备份中；选股原则和网格计划随账本备份。

下载签名 APK 后可直接覆盖更新，沿用原包名及长期签名。已完成自动化与隔离浏览器验证；真实模型服务回答和实体 Android 设备安装、数据保留未实测。
