## 中文

Fortuna 1.5.1 修复资产详情页无法向下滑动的问题，并完善红利预算分配与清单导入。

- 各类资产与负债详情恢复滚动，可以查看底部持仓和明细。大字体以及从持仓导入跳转视觉 API 设置后返回的场景也已验证。
- 删除红利股票时，可选择将释放的资金按剩余股票原占比重新分配，或保留为未分配。确认前显示各股票原占比、新占比及分配金额；包含隐藏标的，0%标的保持0%。
- 新增「分配剩余预算」，可按已有正占比将未分配预算分配到100%。分配完成后直接显示本次计算公式，并可展开查看各股票占比变化。
- 红利页新增「批量导入股票与占比」，支持 XLSX/XLS/CSV/TSV 或粘贴表格，并可导出现有清单作为模板。每只股票可设置不同计划占比，预览中可逐项勾选或全选。
- 导入会提示无效行、重复代码与超预算，确认后整批保存。更新已有股票的计划占比时保留自定买卖网格、手填分红、持股来源和行情缓存。

更新：在「设置 → 关于 → 检查更新」下载，或安装附件 `Fortuna-1.5.1-release.apk`。正式 APK 使用既有长期签名，Android versionCode 升至 11。

验证：172 项自动化测试、Lint、生产构建通过；浏览器覆盖17种账户场景、390px与320px布局、触摸滑动、删除分配预览、清单导入与金额隐藏。未进行物理手机安装复测。

## English

Fortuna 1.5.1 restores scrolling in account details and improves dividend budget allocation and stock list imports.

- Asset and liability details can scroll to their holdings and records again, including large-font layouts and returning from vision API settings with an import draft.
- Removing a dividend stock can redistribute its released allocation in the remaining proportions or leave it unallocated. The preview shows old/new weights and amounts, includes hidden stocks and keeps zero weights at zero.
- Allocate unused budget scales existing positive weights to 100%. The completed calculation is shown on the page, with expandable changes for each stock.
- Import dividend stocks and individual plan weights from XLSX/XLS/CSV/TSV or pasted tables. Export the current list as a template, then select individual rows or all valid rows before saving.
- Invalid rows, duplicate codes and totals above 100% are reported. Matching stocks retain their custom trading grids, manual dividends, share sources and cached market data.

Update through Settings → About → Check for updates, or download `Fortuna-1.5.1-release.apk`. The release retains the permanent signing identity and raises the Android version code to 11.

Validation: 172 automated tests, lint and production build passed. Browser checks covered 17 account scenarios, 390px and 320px layouts, touch gestures, allocation previews, list imports and amount privacy. Physical-device installation has not been tested.
