## Fortuna 8.0.8

- 修复零持仓时因前档预算不足整手而跳到第三档的问题。现在保留第一档目标，单独显示整手限制。
- 修复部分中期分红被数据源误标为季度，已有金额却提示缺资料的问题。按匹配的实施公告标题自动核对所属期。
- 修复共用公告解析器误取税后派现、再次扣税的问题，适用于全部证券。旧提取缓存不再覆盖结构化税前金额；受影响的保存价提示重新确认。
- 精简股票卡片，移除重复依据、最深触价和多处生成时间，集中显示数据更新时间。价格表直接说明分红、税率和首档价格与现价的距离。

更新后在“选股与计划”点“更新并重查全部”重新检查；已有保存价格保留，核对纠正后的价格并确认写入后才更新计划。

Android 请下载下方 `Fortuna-8.0.8-release.apk` 覆盖安装。
