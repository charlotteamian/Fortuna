## Fortuna 1.8.3

- 修复 Excel 备份中 `HoldingTxns` 工作表的格式兼容问题：可选校准字段允许留空，完整文本数字可正常恢复，Excel 日期单元格按工作簿日期系统转换，不改变交易日期。
- 数据校验失败时显示具体行号、字段和原因，方便检查重复 ID、缺失账户或持仓、无效数字和成本校准数据。
- 校验失败不会写入数据；恢复仍以一次事务完整替换账本，写入失败整批回滚。

### 更新

在 App「设置 → 检查更新」下载并安装，或下载下方 `Fortuna-1.8.3-release.apk` 覆盖安装。

包名 `com.fortuna.wealthtracker` 和正式签名保持一致。版本号为 1.8.3，Android versionCode 为 19。
