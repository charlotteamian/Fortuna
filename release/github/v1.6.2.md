## Fortuna 1.6.2

- 优化归档股票历史记录：分行展示买卖方向、完整日期、成交价、股数和成交金额，保留价格精度，适配窄屏和大字体。
- 新增买入 / 卖出汇总、累计股数、平均成交价、已实现盈亏及交易日期范围，方便核对和复盘；持仓校准与实际成交分别显示。
- 展示已有交易备注和成交编号，支持最新 / 最早成交优先排序。编辑、删除改为小图标，删除前可核对所选记录并确认。
- 归档卡片直接显示已实现盈亏和交易日期范围，股票名称继续完整展示。
- 视觉 API 配置作为设置页顶部的独立入口，直接展示配置状态、服务商和模型；截图导入入口跳转到同一设置页，返回后保留尚未确认的预览。

### 更新

在 App「设置 → 检查更新」下载并安装新版，或下载下方 `Fortuna-1.6.2-release.apk` 直接覆盖安装。包名和正式签名保持一致，版本号为 1.6.2，Android versionCode 为 14。

### 验证

184 项自动测试、ESLint、TypeScript 和生产构建通过。浏览器使用独立合成账本，验证中英文、320px / 390px、大字体、交易编辑与删除确认、日期排序、金额隐藏，以及 API 配置持久化和导入草稿保留。

交易金额汇总未包含手续费、税费和分红；盈亏沿用现有账本的移动平均成本。截图识别流程采用模拟 API 响应验证。

本次没有连接的实体 Android 设备，实体设备覆盖安装尚未验证。
