## Fortuna 4.0.1

- 选股检查优先展示生成的四买四卖网格。经营、分红、财报、技术与来源集中在一个“查看全部检查依据”中，展开后直接阅读。
- 只保留一个买卖价格计划预览入口，可在原位预览并确认写入；暂停网格的恢复仍需阅读最新依据后确认。
- 红利首页同时展示股票和基金计划、计划金额与触发情况。基金恢复入场参考价、回撤、指数股息率、持有方式和卖出条件；股票收起分红明细时仍可查看执行计划。
- 首页助手增加“今日操作建议”，一键更新资料并在首页回答。聊天和原有快捷提问继续保留；助手旁的“计划管理”入口改为“选股检查”。
- 今日建议保存在本机并标明生成时间，跨日、计划或持仓变化后提示重新生成；失败或取消时保留上次完成的回答。

正式签名 APK：4.0.1；Android versionCode：36。
