## Fortuna 8.0.9

- 修复辅助行情或财务来源失败时，已核验的新分红价格仍被旧检查日期锁住、无法确认写入的问题。价格与财务资料各自保留真实日期；真正的分红失败、冲突或参数变化仍会阻止写入。
- 重查后在股票卡片直接显示新旧价格差异，点“查看并确认更新”进入现有价格表。确认后更新全部四买四卖，卡片目标同步更新。
- 明确区分“已保存目标”与“本次重算结果”。八档价格相同时显示一致，分红和参数未变化时不会为了版本升级改变价格。
- 数据更新时间集中展示，结构化分红使用资料日期，原公告核验日期保留。

更新后进入“选股与计划”，点“更新并重查全部”。有变化的股票可从卡片提示查看并确认；确认前保留已保存价格。

验证已覆盖真实页面的重查、确认写入、八档读回和重载恢复，使用隔离合成数据。预算、持仓和暂停状态不变；未做实体手机覆盖安装验证。

Android 请下载下方 `Fortuna-8.0.9-release.apk` 覆盖安装。
