## Fortuna 1.8.0

- 红利股票和已加入计划的场内基金报价自动更新：打开红利页或回到前台时更新，页面可见时每分钟刷新；也可点击「立即更新报价」。
- 支持沪市、深市 ETF 和已上市 LOF 的交易报价，保留基金报价的小数精度，并展示行情来源和实际报价时间。休市期间显示最近交易报价。
- 断网或部分行情获取失败时，保留原报价和时间并提示，后续自动重试。手动参考前高、指数股息率及其日期分别保存，报价刷新不会将旧参考数据改成当日数据。
- 设置中的主题配色、本位币/汇率/金价、资产负债类型、常用币种、自动快照和视觉 API 配置默认收起，点击菜单后再编辑。菜单显示当前选择或配置状态。

### 更新

在 App「设置 → 检查更新」下载并安装新版，或下载下方 `Fortuna-1.8.0-release.apk` 直接覆盖安装。包名和正式签名保持一致，版本号为 1.8.0，Android versionCode 为 16。

### 验证

205 项自动测试、ESLint、TypeScript、生产构建和平台资源同步检查通过。使用独立合成账本完成自动刷新、前后台切换、断网恢复、设置菜单编辑，以及中英文、320px / 390px、标准 / 大字体共 24 个浏览器布局检查。

场外基金净值仍使用手动参考数据。实体 Android 设备覆盖安装尚未验证。
