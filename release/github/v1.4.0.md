## 中文

Fortuna 1.4.0 新增红利工作台，并修复计划页的失效关联。

- 底部新增「红利」标签；「设置」移到顶部右侧，保留应用更新与备份入口。
- 计划页自动清理已删除账户／持仓的失效链接；未计入统计的真实账户保留名称并注明状态。
- 红利预算由你填写，按可编辑比例分配到各标的，不再固定为20万元。
- 股数可从现有A股持仓流水自动汇总，也可手填；按近12个月已实施分红估算税前年股息，待实施方案单列。
- 行情、分红和日线使用可核对日期的真实接口数据；失败时明确标记并保留缓存，不再回退到演示行情。
- 保留可编辑的分组与股息率网格，修正累计股数算法；可展开每股净资产、市净率、利润同比及均线、RSI、布林带。
- 工作台配置与数据支持现有 JSON／Excel 备份恢复和自动快照。

本次使用与 GitHub 正式版 1.3.2 相同的长期签名，版本号递增，可覆盖更新并保留本地账本。在旧版的「设置 → 关于 → 检查更新 → 下载并安装」更新；新版设置入口位于顶部右侧。

附件：`Fortuna-1.4.0-release.apk`。预算、股数和估算均在本机处理；查询仅发送公开证券代码。股息为基于历史分红的税前估算，不是已确认应收款。

## English

Fortuna 1.4.0 adds a dividend workbench and removes obsolete plan links.

- New Dividends tab; Settings moves to the top bar.
- Editable budget, stock weights, groups, yield grids, share overrides and dividend overrides.
- Link mainland equity quantities to existing transactions and estimate annual gross dividends from implemented trailing-12-month payouts. Pending plans remain separate.
- Dated quotes and dividends, explicit partial failures, and adjusted daily-price indicators. No demo-data fallback.
- JSON/Excel backup and automatic-snapshot support.

The APK uses the same permanent signing certificate as GitHub 1.3.2 and a higher Android version code. Update through Settings → About → Check for updates → Download and install.
