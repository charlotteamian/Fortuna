## Fortuna 3.5.3

修复仓位阶梯网格的触发判定逻辑，并优化计划页红利股摘要卡片的排版展示：

### 更新内容
- **网格触发逻辑修复**：价格与指数网格不再按相邻两档的中点提前触发，而是严格等到行情跌入对应档位区间（`现价 ≤ 触发价`）再激活该档位；股息率网格同理需真正达到目标门槛（`股息率 ≥ 触发值`）才触发对应仓位；同时适当加宽价格阶梯表首列，避免较长的参考点位文字被省略截断。
- **红利股卡片排版优化**：将现价、税后股息、权重、预算与持仓整理为双列对齐布局，去掉原先杂乱的点号分隔与换行前导点；优化股票名称与代码行距及徽章内边距，避免 4 字股票名与代码换行折断；移除「今日触发」行末的「待更新」统计。

### 安装说明
- 沿用既有正式签名证书与包名（`versionCode 62`），可直接覆盖更新，保留全部本地数据。
