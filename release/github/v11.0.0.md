## Fortuna 11.0.0

- **计划页按子分类层级展示**：设置了子分类的计划卡片统一按「母分类实际占比 → 策略备注 → 子分类占比 → 子分类下计划与仓位阶梯」从上到下展示；卡片内的「金额来源与分项」折叠区移除（分类归属与金额设置仍在编辑弹窗中），每张卡片提供「＋ 添加子分类」入口。
- **红利基金网格移入计划页**：红利资产卡片新增「红利基金」「红利股」两个子分类区块，基金网格以与其他资产一致的仓位阶梯表格展示；档位与仓位比例参照母分类股息率阶梯，档位价格按指数股息率换算为实际要买的基金价格，子分类占比与金额完全跟随 app 中设置的子分类，不设默认对半分。
- **红利股当前触发内嵌计划页**：红利股子分类显示工作台的今日触发摘要与每只股票的触发状态，点击任一股票（无论是否触发）内联展开四买四卖仓位阶梯；股票行不再显示税后股息率，保持排版简洁。
- **红利工作台精简**：只保留 AI 问答与选股计划，基金区块与股票/基金策略切换移除；工作台计划资金自动使用计划页「红利股」子分类金额（顶栏同步显示），不再单独设置；基金计划编辑入口移至计划页红利基金子分类，预算同样随子分类自动同步（预算字段只读）。
- **返回位置保持**：从红利工作台返回计划页时停留在红利资产卡片（或基金区块）位置而不是页面顶部；账户详情返回列表、底部页签切换时也保存并恢复各自的滚动位置。
- **子分类角色**：子分类可绑定「红利基金」「红利股」角色（PlanTarget 新增 `role` 字段，Excel/JSON 备份往返保留），红利基金与红利股的资金分别同步到基金计划与工作台预算。

Android 请下载下方 `Fortuna-11.0.0-release.apk` 覆盖安装，或在 App 设置中检查更新；继续沿用既有正式签名证书与包名（`versionCode 58`）。
