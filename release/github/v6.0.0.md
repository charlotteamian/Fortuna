## Fortuna 6.0.0

- **经典红利股息率阶梯锚定网格策略**：以 5.00% 股息率作为中性价值参考锚，自动计算四买（5.50% / 5.75% / 6.00% / 6.50%）与四卖（4.80% / 4.50% / 4.20% / 4.00%）阶梯价格，每档分配 25% 仓位并按 100 股/手折算目标股数与今日补仓/减仓股数。
- **四级分红基数自动兜底法则**：按「手动指定 > 东方财富最新已实施完整年度周期（自动合并半年报+年报/季报常规分红并剔除特别分红）> 已公告预案与季节递推 > 28 只主流红利蓝筹基准或 5.0% 锚」自动计算，无需人工翻阅公告 PDF 或复核财报。
- **选股即看网格工作台**：顶部提供直观的股票选择栏（支持按今日触发/已持仓/核心池/观察池筛选与搜索），点选任意股票即刻展示今日触发结论横幅、股价位置可视化标尺、四买四卖明细表与一键保存网格按钮。
- **页面内嵌 AI 今日操作顾问**：在红利页直接点击「问 AI：今日全部股票操作建议」或「问 AI：当前股票今日怎么操作」，即刻生成当天具体买卖档位、挂单参考价与股数建议，并支持大模型深度解答。
- **红利税率实时切换**：支持在页面顶栏一键切换 0%（持股超 1 年）、10%（1 个月～1 年）、20%（1 个月内）税率假设，全池网格实时重算。
