## 中文

Fortuna 1.4.1 修复红利工作台的预算保存与标的分配，并简化已有持仓补录和备注查看。

- 已保存的总预算在重新进入后正确回填；修改资产页归档显示、偏好设置或资产计划时，不再覆盖红利预算。零预算也会保留。
- 「补入已有持仓」支持逐只勾选和全选，只补入选中的有效持仓。新标的默认为 0%，股数继续随持仓流水联动。
- 股票备注直接显示在卡片外层，收起明细时也可查看。
- 删除股票后，释放的比例按剩余股票的原有比例重新分配，包含隐藏标的；原先未分配的部分保留，0% 标的保持 0%。删除与比例重算同时保存，原有持仓和流水保留。
- 每只股票卡片同时显示预算占比和分配总金额，金额仍遵循隐藏开关。

验证：87 项自动化测试、Lint、生产网页构建及 Android 测试构建通过；浏览器已验证预算回填、勾选补录、删除重分配、备注保存和 320px 手机宽度布局。未进行真机安装复测。

更新：顶部「设置 → 关于 → 检查更新 → 下载并安装」，或下载附件 `Fortuna-1.4.1-release.apk`。正式包由 GitHub Actions 使用既有长期签名构建，Android 版本号递增，可覆盖同签名的 GitHub 正式版本并保留本地账本。

## English

Fortuna 1.4.1 fixes dividend budget persistence and stock allocation, with easier holding selection and visible notes.

- Saved budgets, including zero, return when the workbench is reopened and survive unrelated preference or plan changes.
- Select individual existing holdings or select all; only selected, eligible stocks are added with linked quantities and an initial 0% weight.
- Stock notes appear directly on the card alongside the budget share and total allocation.
- Removing a stock redistributes its allocation proportionally across the remaining positive weights, including hidden stocks, while preserving unallocated budget and zero weights. Removal and reallocation commit together; holdings and transactions are retained.
- New allocation amounts respect the amount visibility switch.

Validation: 87 automated tests, lint, production web build, Android debug build and browser checks passed. Physical-device installation has not been retested.

Update through Settings → About → Check for updates → Download and install, or download `Fortuna-1.4.1-release.apk`. The release workflow uses the existing permanent signing certificate and a higher Android version code.
