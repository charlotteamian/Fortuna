## Fortuna 1.8.1

- 更新失败原因会保留在「应用更新」下方，直到重新检查或重试；可展开「错误详情」截图，解决短提示来不及查看的问题。
- 明确区分连接超时、下载服务器不可达、下载不完整、存储空间不足和签名/安装包校验失败。
- 下载连接失败自动重试一次；重新从 GitHub 正式地址取得下载跳转，避免重复使用过期的临时下载地址。
- 下载时分别显示连接、下载进度和安装包核对；网络失败可选择「重新下载」或「用浏览器下载正式 APK」。
- 保留 HTTPS 来源、包名、更高版本号和长期签名校验，安全校验失败仍会停止安装。

### 更新

如果旧版 App 的下载一直停在 0%，请用浏览器下载下方 `Fortuna-1.8.1-release.apk`，打开并按系统提示覆盖安装。无需卸载现有 App。

包名 `com.fortuna.wealthtracker` 和正式签名保持一致。版本号为 1.8.1，Android versionCode 为 17。包括 1.8.0 的红利自动报价和收起设置菜单。

### 验证范围

前端自动测试、原生下载连接测试、检查与构建，以及模拟下载的错误持久显示、连接/下载/核对阶段、重试、浏览器入口和安全失败拦截均已检查。已用正式 1.7 包在 Android 模拟器复测 GitHub 下载及安装包校验。

特定手机的失败原因仍需实际错误详情确认；模拟器检查不代表该手机已验证。
