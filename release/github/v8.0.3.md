## Fortuna 8.0.3

- 修复现金股息率复核：使用已核验的分红基数与有效价格重新计算，避免缓存指标或无关技术数据让检查反复变成未知。
- 简化选股与计划页面，核验细节、来源和历史网格说明收进详情；保留会影响当前决策的具体问题。
- 修复部分半年分红股票的台账批次合并与网格生成阻断；真正缺少必要数据时，可按提示补录后重新生成预览。
- 股票 / ETF 组合可选择现金倒减模式：初始金额 + 已实现盈利 - 已实现亏损 - 当前持仓市值。
- 图表中的单位净值按你选择的已命名投资组合统计，可自由开启或关闭。
- 配置计划可直接修改各类资产占比，不再受子分类及其他分类的上下限锁定；备注支持完整多行文本，总额与当前资产金额采用更紧凑的布局，移除自动资金调拨顺序展示。

### 安装与更新

下载 `Fortuna-8.0.3-release.apk` 覆盖安装，沿用既有包名和长期正式签名。Android versionCode 47，iOS 元数据 build 47。
