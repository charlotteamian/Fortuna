# Fortuna 2.0.0

- 红利助手按提供的定价文档，计算可持续分红 D₁、三个收益率锚、Gordon／PB–ROE 校验、安全边际和三档网格。方法参数、机会成本及单股归一盈利依据可保存。
- 自动抓取个股与指数走势、历史分红／未复权月线、财务／现金流、十年国债及中证官方红利指数股息率，计算卡保留来源和日期。缺失或冲突直接列在对应结果中。
- 红利页显示最新报告的单期预计／公告分红，单独预测从今天起持有一年的分红。新公告替换同一期历史预测，已除权事件不重复计入；未披露金额或资格日期不足时不冒充完整预测。
- 页面精简为行情、报告分红和持有一年预测。预算、股票／基金策略、导入和网格调整集中到助手的“计划管理”，详细内容分组折叠。
- 三档网格先预览、再确认写回；下跌加速可暂停加仓。历史聊天、选股原则、经营风险检查及持仓保护继续保留。有持仓的股票不能从计划删除。
- 定价参数随 JSON／Excel 账本备份和全资产快照保存；旧账本和旧缓存可继续导入，旧 TTM 缓存自动刷新到新口径。

本次为功能大更新，版本升至 2.0.0。后续功能大更新递增主版本，修复递增末位。Android 内部版本号 23，沿用原包名和长期签名，可直接覆盖更新。
