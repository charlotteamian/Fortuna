# Fortuna 2.0.1

- 红利首页恢复每只股票的买卖计划，直接显示各档价格、累计目标股数、预算和当前持仓，可直接调整计划。排序为已持仓优先，其次核心、观察。
- 选股原则补充默认参数说明与逐项填写指引。机会成本默认自动获取，手工覆盖和周期股归一盈利均提供来源及填写路径。
- 选股检查先给综合建议、依据和下一步条件，再展开财务与技术明细。指数环境作为分析依据，不再占用独立展示板块。
- 腾讯日线和历史月线增加备用地址与重试，失败保留具体来源和诊断；日期键统一为稳定格式。自身历史股息率保留样本数和区间，缺失与估值锚冲突给出对应处理路径。
- 银行按资本、不良率和拨备指标实际复核；证券核对风控指标，保险保留偿付能力及尚缺项目的具体结论。金融企业不再套用工业企业现金流指标。

Android 内部版本号 24，沿用原包名和长期签名，可覆盖更新。
