## Fortuna 3.0.0

### 股票、ETF 与黄金价格监控

- 在资产页的股票/ETF、黄金分类，以及对应账户详情中管理价格监控。没有持仓或已经清仓，也可以继续关注。
- 自行设置目标价格、跌至或涨至条件，以及目标价上下多少百分比开始提醒。股票按所属市场币种，黄金按所选币种/克计价。
- 进入提醒范围后每天在 App 顶部提示一次；达到或越过目标价后提示并自动结束。可以随时关闭本次提醒、停止监控、修改条件或重新开启。
- App 启动、回到前台及打开期间每天检查，也可手动刷新；刷新持仓价格时同时检查监控。此版本使用 App 内提醒，关闭 App 后不会后台轮询或发送系统通知。
- 报价失败会保留原报价和具体检查状态，不使用离线旧缓存触发新提醒。监控计划随 JSON、Excel 备份及自动快照保存。

### 行情与兼容

- 修复北交所 920 开头股票和带点美股代码的行情识别。
- 沿用正式签名，可直接覆盖安装保留本机数据。
