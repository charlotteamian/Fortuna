## Highlights / 重点

Fortuna 1.2.0 turns the app from a private, highly customized tracker into a general-purpose local-first wealth manager. It adds complete onboarding and help, flexible portfolio accounts, reusable allocation planning, public-safe exports, and a reproducible synthetic demo.

Fortuna 1.2.0 将原本高度定制化的资产追踪工具改造为通用的本地优先财富管理 App，完整补齐首次引导、使用说明、组合账户、资产配置、通用快照与公开演示数据。

## Experience / 体验

- First-install walkthrough and complete in-app user guide.
- Chinese/English UI, theme and text-size controls, amount masking, and responsive large-text layouts.
- Account-detail amount toggle, collapsed archived positions, and collapsible value snapshots.

## Core features / 核心功能

- Multi-account assets, liabilities, currencies, net worth, and historical charts.
- Portfolio cash, quantity/price holdings, balance-based products, archives, transaction history, and cumulative P&L.
- Multi-level allocation plans with exact account/holding/cash links and safe shared-resource allocation.
- US option contracts with OSI-compatible fields and 100x multiplier-aware valuation.
- Complete Excel backup/restore and optional portable JSON snapshots.

## Performance and fixes / 性能与修复

- Startup no longer waits for nonessential background refresh or snapshot migration.
- Fixed large-font overflow, sold-out return ratios, balance flows, rate response handling, local-date boundaries, portfolio valuation, and snapshot migration.
- Android splash and background behavior are consistent with the app theme.

## Demo and privacy / 演示与隐私

- GitHub screenshots and the included demo workbook use deterministic synthetic data only.
- No real personal account, position, or transaction data is included in this release or repository.
- Financial records remain local by default; no Fortuna login, analytics SDK, or advertising SDK is required.

## Install / 安装

Download `Fortuna-1.2.0-debug.apk` below and open it on an Android device. This is a debug-signed sideload build for personal, non-commercial use, so Android may ask for permission to install unknown apps.
