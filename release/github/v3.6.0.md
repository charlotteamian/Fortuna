## Fortuna 3.6.0

新增交易手续费自动计算（支持全局默认费率与按票自定义），以及当日做 T 匹配（LIFO）与 `T` 徽章展示：

### 更新内容
- **交易手续费自动计算与费率设置**：
  - 全局默认佣金费率默认为 `0.01%`（万分之 1），可在「设置 → 交易手续费」随时调整；股票/ETF 买卖自动按成交额计算手续费，并统一计入买入成本、已实现盈亏、摊薄成本、月度盈亏、倒减现金与组合单位净值。
  - 支持在每只持仓中单独覆写费率（可按票修改，填 `0` 表示免佣，留空继承默认费率），也支持在单笔交易记录中手动覆写手续费；持仓展开页点击「手续费 (0.01%) ✏️」即可快速修改该标的费率。
  - 费率、单笔手续费与当日做 T 标识完整支持 JSON/Excel 备份还原及便携快照导出。
- **当日做 T 匹配（LIFO）与 `T` 标记**：
  - 持仓盈亏核算升级为当日做 T 优先配对（支持先买后卖「正T」与先卖后买「倒T」）+ 跨日 LIFO（后进先出）结转。
  - 命中当日做 T 配对的买卖记录自动展示 `T` 徽章，并列出配对股数、买卖价与扣费后的做 T 净盈亏；持仓展开卡片同步展示「当日做T盈亏」与匹配笔数。

### 安装说明
- 沿用既有正式签名证书与包名（`versionCode 64`），可直接覆盖更新，保留全部本地数据。
