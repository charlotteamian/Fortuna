## One-time signing transition / 一次性签名迁移

**Back up before installing.** Fortuna 1.3.0 is the first GitHub APK signed with the permanent Fortuna release key. Android cannot install it over 1.2.1 or any earlier debug-signed build.

**安装前请先备份。** Fortuna 1.3.0 是首个使用长期固定签名的 GitHub APK，Android 无法把它直接覆盖安装到 1.2.1 或更早的 debug 签名版本上。

1. In the old app, open **Settings → Backup & Restore** and export a complete Excel backup outside the app.
2. Uninstall the old Fortuna app.
3. Install `Fortuna-1.3.0-release.apk` from this release.
4. Restore the Excel backup in the new app.

1. 在旧 App 中进入 **设置 → 数据备份与恢复**，把完整 Excel 备份保存到 App 外部。
2. 卸载旧版 Fortuna。
3. 安装本页的 `Fortuna-1.3.0-release.apk`。
4. 在新版中恢复 Excel 备份。

This is the last planned uninstall transition. Releases after 1.3.0 keep the same signing identity and can update in place.

这是计划中的最后一次卸载迁移。1.3.0 之后的版本会保持同一签名，可以直接覆盖升级。

## In-app updates / App 内更新

- Added **Settings → App Update / 设置 → 应用更新** on Android.
- Checks only the official latest GitHub Release and shows its release notes.
- Downloads the release APK inside Fortuna and opens Android's standard installation confirmation.
- If Android asks, allow Fortuna under **Install unknown apps**, return to Fortuna, and continue installation.
- Android does not permit Fortuna to silently install an APK without user confirmation.

## Update security / 更新安全

Before opening the installer, Fortuna verifies all of the following:

- the initial HTTPS URL belongs to this repository's official GitHub Release;
- the APK package name is `com.fortuna.wealthtracker`;
- the APK version code is higher than the installed version;
- the APK signing certificate exactly matches the currently installed Fortuna app.

CI also pins the public certificate SHA-256 fingerprint and refuses to publish if a different signing key is used.

## Privacy / 隐私

Update checks request public release metadata from GitHub. The request does not include your accounts, balances, holdings, or backup data. Financial records remain local unless you explicitly export or share them.

检查更新只会向 GitHub 请求公开的版本信息，不会发送账户、余额、持仓或备份数据。财务数据仍保存在本机，除非您主动导出或分享。
