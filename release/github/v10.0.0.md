## Fortuna 10.0.0

- **方案 A 计划管理重构**：底部导航精简为「资产 · 计划 · 净值 · 账户」四个页签，将红利个股算价与排雷工作台整合为计划页的二级子页面，支持一键进入与返回，并自动同步红利板块配额预算。
- **四种计划管理方式可选**：新建或编辑计划时可选择「📊 阶梯网格模式」「💎 个股/基金卡片」「🌱 红利价值组合」「📝 基础配额+备注」，支持为尚未持有的资产提前建立计划，并保留完整的新增、编辑、排序与删除计划能力。
- **仓位阶梯表与自动现价高亮**：内置黄金(518850)、创业板ETF(159915)、原油(513350)、红利股息率(8.0%~3.0%)等阶梯模板并支持自由增删微调行；自动拉取代码现价并高亮当前所处档位，动态计算「当前应持仓金额」「待机备用金」及下一档加减仓提示。
- **全局活钱蓄水池自动对账**：汇总所有板块未打满的待加仓备用金需求，与银行存款、理财产品、现金及券商闲置现金构成的活钱池自动比对。
- **排版与对齐全面优化**：采用严格的 2 列 × 3 行数值对齐网格锁定「当前应持仓」与「实际持仓」基线；阶梯表采用 4 列全显紧凑布局防止窄屏裁切；卡片标题居首行、权重与配额统一居次行左对齐；去除金额前冗余的人民币符号。

Android 请下载下方 `Fortuna-10.0.0-release.apk` 覆盖安装，或在 App 设置中检查更新；继续沿用既有正式签名证书与包名（`versionCode 56`）。
