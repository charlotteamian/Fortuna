## Fortuna 1.7.0

- 已归档持仓增加名称或代码搜索，支持 A 股、美股、港股等市场筛选，以及起止时间范围筛选。
- 新增日期、名称、已实现盈亏金额的正向和反向排序；展示匹配数量，支持一键重置。
- 增加筛选结果的已实现盈亏合计，展开仍可核对完整交易历史。日期按持仓最后一笔交易或校准记录计算，时间范围包含起止当天。
- 将检索工具扩展到已归档基金、存款、理财等账户内产品；首页的已归档账户也支持名称、机构或产品代码搜索、分类筛选，以及归档日期和名称排序。
- 设置增加六套配色：紫晶 / 香槟、珊瑚 / 海蓝、靛蓝 / 杏橙、青竹 / 丁香、蜜金 / 烟灰、蔷薇 / 冰蓝。共十一套，分别适配浅色、深色模式，保存后重新打开仍保持选择。

### 更新

在 App「设置 → 检查更新」下载并安装新版，或下载下方 `Fortuna-1.7.0-release.apk` 直接覆盖安装。包名和正式签名保持一致，版本号为 1.7.0，Android versionCode 为 15。

### 验证

196 项自动测试、ESLint、TypeScript 和生产构建通过。使用独立合成账本完成中英文、320px / 390px、大字体、浅色 / 深色的浏览器检查，覆盖组合检索、六种排序、完整历史记录、其他资产归档、配色持久化和金额隐藏。

持仓日期筛选作用于列表，盈亏合计对应所列持仓的完整已实现盈亏，沿用原有账本口径。余额型产品使用日期和名称排序。

本次没有连接的实体 Android 设备，实体设备覆盖安装尚未验证。
