# Fortuna 2.0.3

- 修复红利股重新生成网格被三锚分歧阻断的问题。三锚改为辅助校验：完整且接近时取中位收益率，分歧或部分缺失时取有效锚中最高收益率，再与 Gordon 和可用 PB 估值比较，采用较低价格。
- 正值自由现金流覆盖不足 150% 时，核对近三年最弱每股现金支持并限制可持续分红，仍可生成条件计划；缺失或非正值现金支持继续明确提示。银行使用专项审查，不套用工业企业现金流规则。
- 重新生成计划时，程序直接补充已计算的三档草案。下跌加速时保留新价格并暂停加仓，避免新网格被暂停提案覆盖。
- 定价卡展示采用的收益率、每股现金流上限、最终保守评估价与三档。辅助锚价不再被当作无法落实的手动建议。
- 所有新网格先预览再确认写入，保存为暂停加仓的条件计划，恢复加仓另行复核。

Android 内部版本号 26，沿用原包名和长期签名，可覆盖更新。
