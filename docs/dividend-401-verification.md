# Fortuna 4.0.1 验证记录

选股检查把四买四卖表格与唯一的价格预览入口放到股票卡片前部。原则、财报、分红、技术、来源和风险明细集中到一个折叠区，展开后无需逐项再开菜单。暂停恢复单独保留核查、阅读、预览和确认流程。

红利首页同时显示股票与基金计划。基金展示独立预算、计划金额、入场价、回撤、指数股息率、持有方式和卖出参考；长期持有与年度再平衡不会因回到前高新增卖出信号。股票收起分红明细后，执行网格继续可见。

首页增加直接回答的今日操作建议，聊天内的快捷提问保留。本机保存生成时间与计划范围，股票／基金持仓、原则、税期变化或跨日后提示重新生成。报价下载时间变化不会让建议误报“计划改变”。生成失败、取消与迟到回答不会覆盖上次完成的建议。

本地验证：480 项自动测试、ESLint、TypeScript／Vite 构建、diff 检查通过。Android 与 iOS 完成 Capacitor 同步；iOS 版本 4.0.1 / build 36 的 45 个网页资源核对通过。

隔离 Chrome 通过 29 项检查，覆盖 320／390 像素与 1.3 倍字体、基金触发显示、预览不写入、确认同时更新买卖两侧并保留持仓和手动暂停、暂停恢复的阅读确认、首页建议及其持久化／失败／取消／时效提示。浏览器使用合成账本、历史分红样本及模拟研究／行情／模型传输，不代表真实模型或实体设备验证。详细结果见 `dividend-401/browser-validation.json`。

正式签名包、GitHub 工作流与更新解析验证记录在 `dividend-401/`。本机未连接 Android 设备，本次没有实体手机或模拟器覆盖安装结果。
