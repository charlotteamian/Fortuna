## 结论与优先顺序

**v5 主公式、税和取整复算正确；当前不可靠的地方主要是价格来源、核验状态、行情适用性和执行资格没有贯通。现有测试全通过，仍不足以证明这些业务边界正确。** 建议先统一只读状态并建立防误报测试，再缩短手机页面，最后接确定性今日检查和可选 AI 解释。

最应优先处理的具体问题：

| 优先级 / 问题 | 已复现的现状 | 下一步最小处理 |
| --- | --- | --- |
| 高：旧定价回退绕过 v5 | 无已保存显式网格、无核验台账，只有手工/预测股息，首页仍生成税前旧七档。示例 0.609 元股息得到首档 12.18 元，并标触发。 | 摘要标清价格 origin；没有可靠新价或合法显式旧价时不输出执行价。已有历史计划不删除、不迁移。 |
| 高：失败刷新被聚合为已核验 | 10/29 缓存公告，10/30 官方查询模拟 503；原文 verifiedAt 没改，但新 ledger.asOf=10/30，base.verified=true，允许新草案，首页也显示 verified。 | 分开“本次尝试”“成功覆盖”“文档原核验”；失败保留历史数据，不能升级可信状态。 |
| 高：到价与操作资格分离不完整 | 手动暂停、ROE 失败、专项缺证时，研究 decision 仍为 eligible（实际只表示到价），首页则 paused。 | 同时展示资格、触价和 actionCheck；手动暂停不建议新增，原则失败到价时明确先复核，不写暂停或改价。 |
| 高：AI 与首页行情口径不同 | 29 天旧报价或当日刷新失败：首页 quote_missing，AI 快照却仍传“价格达到档位=true”。 | 全部消费同一 trigger，保留旧价日期；历史比较不能称今日可执行。 |
| 高：旧表单可覆盖新数据 | 表单打开后记录更新为买价 9 元、暂停、200 股；旧表单只改备注保存，恢复成旧买价 10 元、未暂停、100 股。 | 独立提交编辑指纹/字段冲突保护；不重做账本。 |
| 中：有效性漏项 | 首页未传当前税率，10%→20%仍可能 verified；新网格可拿除息前报价判触发。 | 摘要集中传税率/版本/事件日，行情和计算基数必须可比。 |
| 中：无 AI 就没有本轮今日清单 | 点击今日建议直接去 AI 配置；本轮确定性结果为 0。模拟模型纯文本可违背暂停约束，尽管数值动作被限制。 | 先生成代码决定的清单，AI 只解释；无配置/失败/超时均保留本轮结果。 |
| 中：原始依据保存不足 | 网格来源只有生成日、税前总额、税率、版本、基数种类；恢复主备份后不能定位生成时两份公告。 | 阶段 1 明示证据缺口；依据快照的持久化扩展另提方案并确认，禁止补造历史来源。 |
| 中：基金参考与行情混用 | 无 quote 的同日手工参考价可产生 entry=met / exit=triggered。基金本身未套用股票公式。 | 保留原基金公式，区分“参考条件满足”和“适用行情可确认”，不称参考价为成交行情。 |
| 中：单项异常缺少隔离 | 一只损坏模拟 ledger 可使首页 basis 整批加载失败。 | 单项返回 unknown+原因+重试；不清库、不删除坏记录。 |
| 体验：折叠未收起实际计划 | 十只股票全部收起，20 张四买四卖表仍可见。 | 阶段 2 将完整计划放进折叠体，收起保留下一档及状态摘要。 |

## 复算结果与异常原因分类

归档平安银行公告：2025 年度每 10 股 3.60 元，2026 中期每 10 股 2.49 元，税前合计 **0.609 元/股**。这是固定历史算术样本，未声称今天重新核验或当前适合买卖。

| 用户税率 | 税后元/股 | 四买（元，向下取分） | 四卖（元，向上取分） |
| --- | --- | --- | --- |
| 0% | 0.609000 | 11.07 / 10.59 / 10.15 / 9.36 | 12.69 / 13.54 / 14.50 / 15.23 |
| 10%（默认） | 0.548100 | 9.96 / 9.53 / 9.13 / 8.43 | 11.42 / 12.18 / 13.05 / 13.71 |
| 20% | 0.487200 | 8.85 / 8.47 / 8.12 / 7.49 | 10.15 / 10.83 / 11.60 / 12.18 |

两侧使用同一税后基数，各档25%；微元÷收益率基点得到价格分。0.5481÷5.5%=9.96545…，首买向下为9.96；首卖0.5481÷4.8%=11.41875，向上为11.42。未重复扣税，没有价格安全边际、PB 或国债对档位的暗中修正。

异常样本已区分四类原因，而不是一律要求用户复核：

| 原因 | 典型输入 / 当前结果 | 应如何处理 |
| --- | --- | --- |
| 抓取失败 | 官方查询503，有旧公告，却被聚合为当日verified | 自动重试失败来源；保留旧数据、旧核验日；本轮覆盖未知 |
| 缺少资料 | 所需公告未核验、频率历史不足、送转未知 | 明确字段/批次缺项；不退回更早批次凑金额；有旧价展示旧价，无旧价则无价 |
| 来源冲突 | 最新批金额/日期/送转两源不一致 | 阻断可靠新价，指出冲突两源及日期；不取平均、不择较高值 |
| 公式/路径错误或规则不明确 | 旧七档回退；特别分红可能替换普通年度分红 | 旧路径问题用状态与来源隔离修复；特别分红纳入规则先说明影响、等待确认 |

模拟年度一批、相邻半年两批、同批重复、冲突不回退、送转归一和“严格超过25%”边界复算均已记录。完整价格、关键分子、证据、保存计划与修法见 [典型异常清单](pricing-audit.md) 及 [机器可读样本](pricing-samples.json)。

## 统一状态与页面结构设计

设计稿仅用于下一阶段，尚未添加生产类型或存储字段：

| 区块 | 状态 / 责任 |
| --- | --- |
| eligibility | pass / fail / unknown；用户规则结果，最多三条主要原因；已知失败与缺证并存，不用风险数量评分 |
| grid | verified / saved_unverified / unavailable；区分新核验值与保存计划；附四买四卖、税前税后、税率、批次、版本和来源可得性 |
| trigger | triggered / not_triggered / unknown；明确比较的是哪份网格、哪日哪类行情；最后可用报价与今日适用状态分开 |
| risk | blocking / attention / evidence_insufficient；原因、来源及日期、影响、自动修复能力和未修复处理，主题去重 |
| actionCheck | blocked / review / wait / confirmation_candidate / unknown；手动暂停、原则失败、资料、预算、持仓、整手分别解释；不能自动交易或改计划 |
| freshness | 研究生成、本轮尝试、行情源时点、财报期、发布日、原文核验日与覆盖率分别显示；下载不等于核验 |

同一只读摘要供首页、选股详情和今日检查使用；股票和基金仅共用状态框架，各自调用原有计算。详细字段、决策优先级、未知状态与回归矩阵见 [状态模型设计](risk-audit.md)。手机页面入口与折叠层级见 [UI 信息架构图](ui-data-audit.md)。

### 需先确认、不可夹带实施的事项

- **特别分红如何纳入基数**：当前 special 不参与判频，却参与最近 N 批，可能替换正常年度分红。模拟特别分红2元替换年度0.5元，默认首买从8.18元变32.72元。需明确是单列、附加还是替换后才能改规则。
- **缺年报交叉证据是否阻断新计划**：当前公告现金已核验但 EPS/派息率缺失时标 CROSSCHECK_MISSING，仍可生成价。阶段1应明确“现金核验”与“交叉未知”；若要全面禁止新计划确认，这是新增门槛，先确认。
- **永久自动禁买/暂停或改变比较阈值**：本轮 actionCheck 按任务书提示“先复核”不等于写 buyPaused。若要将一般风险、趋势或具体阈值变成永久硬阻断，或修改旧10天参考窗口，必须另列规则与影响确认。
- **生成证据快照持久化**：新增批次/URL/hash等保存结构和备份格式需先给兼容及回退方案；阶段1只披露缺口，不改变真实账本schema，不回填不存在的历史依据。
