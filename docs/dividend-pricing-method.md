# 红利助手的定价与分红口径

本规则根据用户提供的《红利股网格定价Prompt.md》实现。参数属于用户的红利计划，在助手的“选股原则／定价方法”中修改，随 JSON、Excel 账本备份及全资产快照保存。历史聊天保留当时讨论，新的研究始终重新使用当前参数和数据。

## 三种每股分红分别使用

- 红利页：最新已公开报告对应的单期公告／预案分红，保留报告期、公告日和进度。中期不乘二，季度不乘四。金额尚未披露就显示待披露，旧 TTM 缓存需刷新。
- 持有一年预测：从今天开始，按未来一年可参与的分红事件计算。尚未公告的相同报告期，参考最近一次已实施金额和季节；已有新公告就替换该期历史预测。已过登记日或今日已除权的本次分红不能算成今天新买可领取。未确定的日程标为估计，缺金额不把已知部分当作全年总数。
- 助手估值 D₁：三年归一扣非每股收益均值 × 五年保守派息率 × 税后保留比例。它不等于最新单期公告，也不等于持有一年预测，不再重复乘一次增长率。周期股可填写带日期和依据的归一收益。

旧手填每股分红是网格的全年假设，不能覆盖最新报告显示。原收益率网格用完整的一年预测或手填全年假设；原显式价格保留。新方法先生成三档显式买价，预览确认后才写回计划。

## 定价顺序

1. 获取三年扣非 EPS、五年分红／派息率、ROE、PB、现金流／资本支出、历史分红与未复权价格、国债收益率及来源日期。
2. 明确要求总回报 r、增长 g、持有期和安全边际。默认 r 为 8%、g 为 0%、安全边际为 15%；g 范围为 0–3%，且须小于 r 减 2 个百分点。税率按所选持有期使用文档的 0%／10%／20% 假设。
3. 列出三个现金收益率锚：十年国债加行业溢价、自身历史 70–80 分位、可比机会成本。缺必要锚、数据过期或三锚最大差超过 100 个基点时，展示缺口／冲突，不生成可写入网格。
4. 将三锚中位数形成的价格、Gordon 的 D₁/(r−g) 价格以及 PB–ROE 桥校验分别列出，再采用保守价格约束；不把 r−g 与三锚中位数假装成同一个输入。
5. 单独给出安全边际买价 P×(1−边际)，并按 P 的 95%、85%、75% 生成三档，每档约三分之一。95% 档不等于满足默认 15% 边际，逐档明确是否满足。
6. 结合个股日线与指数评估加仓节奏。下跌加速时提出暂停加仓及复核条件，不能仅因触价或高股息率提出加仓。

原文“PB 偏贵时下调收益率”的方向会提高价格，程序采用更高要求收益率／更低价格约束。高派息、不可持续收益和现金覆盖不足分别阻断或列为具体核查项；金融企业的现金流不套用工业企业口径。

## 抓取与确认

自动抓取腾讯行情／日月线、东方财富分红、派息日程、财务指标、现金流和国债数据，保留报告期、公告日、价格基准及来源。历史收益率锚使用当时已实施现金分红和未复权收盘价，不能把未来公告倒灌到历史。

腾讯日线和未复权月线主地址失败或返回不可验证数据时，通过腾讯公共代理地址重取一次。仍失败时保留实际地址、请求／解析错误及尝试次数。自身历史锚必须有至少60个月度样本、跨度至少4.8年且最近完整月数据不超过40天，不因抓取失败降低要求。当前未复权价格与历史完整月样本分别处理。

### 金融业自动专项初筛

银行、保险、证券直接解析同一财报主源中的行业专属字段，逐项报告数值、阈值、报告期及同比变化。金融业不显示或套用工业企业的负债率、经营现金流／利润、自由现金流／分红规则。专项初筛未知或未通过时，暂停生成可写入的网格，不能仅显示“另行复核”后放行。

- 银行：总资本充足率至少12%、核心一级资本充足率至少9%、不良贷款率不超过3%、拨备覆盖率至少150%。这些是本产品的红利初筛参考线，不等于监管合规结论。[《商业银行资本管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1134197&itemId=4214)规定的最低资本、储备资本、系统重要性附加资本及第二支柱要求不能合并成对所有银行都适用的一条监管线。本初筛未逐家核验后几项要求。
- 证券：风险覆盖率至少100%、资本杠杆率至少8%、流动性覆盖率及净稳定资金率均至少100%，依据[《证券公司风险控制指标管理办法》第十七条](https://www.csrc.gov.cn/csrc/c106256/c1653957/content.shtml)。结构化指标达到公开最低线不代表已核验全部监管要求。
- 保险：自动核对综合偿付能力至少100%。主源尚未提供核心偿付能力及风险综合评级时，必须具体标明缺少这两项，不能以综合偿付率代替。[《保险公司偿付能力管理规定》第八条](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=962016&generaltype=0&itemId=925)要求核心偿付能力至少50%、综合偿付能力至少100%及风险综合评级B类以上同时满足；核心偿付能力或风险综合评级未知不判为整体通过。补充依据应来自该公司的季度偿付能力报告，不能填推测值。

中国平安601318另附2026-10-21已核验的[集团2026半年偿付能力报告摘录](https://group.pingan.com/resource/pingan/IR-Docs/2026/Summary-of-Solvency-Report-of-PAG-for-1H-2026.pdf)：报告期2026-06-30，发布日2026-08-21，PDF第22页核心165.60%、综合198.14%，第24／34页明确集团风险评级尚未开展而不适用。此补充明确标为已核验报告摘录，不称实时抓取；不挪用寿险或产险子公司指标。较新的财报期出现、结构化值与该期不符，或报告超过230天时停止应用。其他保险公司仍须用自身证据，不能继承平安集团“不适用”的结论。原PDF SHA-256为`aae32edfa330a1e206e7f9f91afd55c44cb1360880b55ba3258a7588b7423958`。

专项初筛仅使用截至研究日已经发布的报告，超过230天的行业指标视为过期。它不替代原始财报全文、审计意见或公司特定监管要求的核查。

结构化财务数据与全文财报解读分开标注，无法取得的项目明确列出。选股检查与短期技术节奏分开；缺数据不等于不符合原则。计划移除只处理用户确认且没有持仓的股票，删除时再次核对手工、关联、隐藏、归档及未来已记交易。

模型给出的网格必须与程序算得的三档一致才能成为价格草案；未满足定价条件时仍可提出暂停。所有价格变更先预览，再确认写回，买价与原卖价交叉时要求先协调原计划。

## 版本规则

功能大更新递增主版本，例如 1.10.0 → 2.0.0；修复递增末位，例如 2.0.0 → 2.0.1。Android versionCode、iOS build number 始终递增。
