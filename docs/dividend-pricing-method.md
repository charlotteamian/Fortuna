# 红利助手的定价与分红口径

本规则根据用户提供的《红利股网格定价Prompt.md》及后续明确口径实现。2026-10-22 按用户修订：三锚估值作为主估值，Gordon 与 PB 仅作独立参考，不再以三者最低价压低计划。估值与是否加仓分别判断；能算出可持续分红和有效三锚收益率，就生成可预览保存的价格计划。2026-10-23 按用户修订：仓位以已保存的价格档位、预算与持仓为主；经营、分红及技术风险改为软提示，未通过与待补充分开，不自动暂停加仓。参数属于用户的红利计划，在助手的“选股原则／定价方法”中修改，随 JSON、Excel 账本备份及全资产快照保存。历史聊天保留当时讨论，新的研究始终重新使用当前参数和数据。

## 三种每股分红分别使用

- 红利页：最新已公开报告对应的单期公告／预案分红，保留报告期、公告日和进度。中期不乘二，季度不乘四。金额尚未披露就显示待披露，旧 TTM 缓存需刷新。
- 持有一年预测：从今天开始，按未来一年可参与的分红事件计算。尚未公告的相同报告期，参考最近一次已实施金额和季节；已有新公告且披露金额，才替换该期历史预测。下半年／年报或其他单期公告尚未披露每股金额时，使用上一年完全相同报告期的已实施金额估算，明确标出原报告期和“本期金额未披露”，不把上半年分红乘二，不跨到更早年份，也不把预案当作已实施。明确不分红、取消分红和一次性特别分红不沿用往年金额。已过登记日或今日已除权的本次分红不能算成今天新买可领取。未确定的日程标为估计；缺少去年同期可用金额时，不把已知部分当作全年总数。
- 助手估值 D₁：先以三年归一扣非每股收益均值 × 五年保守派息率（五年实际派息率的中位数，估值上限为100%）形成盈利口径税前分红。非金融企业再取该值与现金支持上限的较低者，最后扣除持有期税率。它不等于最新单期公告，也不等于持有一年预测，不再重复乘一次增长率。周期股可填写带日期和依据的归一收益。

旧手填每股分红是网格的全年假设，不能覆盖最新报告显示。原收益率网格用完整的一年预测或手填全年假设；原显式价格保留。新方法同时生成三档显式买价和四档显式卖价，预览确认后一起写回计划。

## 定价顺序

1. 获取三年扣非 EPS、五年分红／派息率、ROE、PB、现金流／资本支出、历史分红与未复权价格、国债收益率及来源日期。
2. 明确持有期和安全边际，并保留 Gordon 对照使用的总回报 r、增长 g。默认 r 为 8%、g 为 0%、安全边际为 15%；g 范围为 0–3%，Gordon 参考价要求 g 小于 r 减 2 个百分点，不满足时排除该参考并提示复核，不影响独立三锚估值。税率按所选持有期使用文档的 0%／10%／20% 假设。
3. 列出三个主估值现金收益率锚：十年国债加行业溢价、自身历史 70–80 分位、可比机会成本。三个锚均有效且最大差不超过 100 个基点时取中位数；差异更大或仅部分有效时，取有效锚中最高收益率，对应较低价格。缺失、过期或口径未经核实的锚明确提示并排除，不能填零或用默认值补齐。全部三锚不可用时明确列出缺口，需补充至少一个带日期和来源的有效收益率锚；不自动替换为 Gordon，也不填默认锚。
4. 主估值 P = D₁ ÷ 第3步选定的三锚收益率。单独列出 Gordon 的 D₁/(r−g) 价格和有效的 PB–ROE 桥估值供比较，不取三者最低价，也不让参考价覆盖三锚主估值。ROE／PB 缺失时列为复核项并排除该参考。不把 r−g 与三锚收益率假装成同一个输入。价格以整数分保存并向下取整。
5. 单独给出安全边际买价 P×(1−边际)，并按 P 的 95%、85%、75% 生成三档买入，每档约三分之一。95% 档不等于满足默认 15% 边际，逐档明确是否满足。为补全卖出计划，沿用原默认买卖收益率梯度的相对关系（500 基点首买对应 450／400／350／300 基点卖出），将本次主锚收益率依次乘 90%／80%／70%／60% 后向下取整至整数基点，以同一 D₁ ÷ 各档卖出收益率计算四档卖价，价格向下取整至分，每档25%、累计25%／50%／75%／100%。这是补全计划采用的显式默认卖出方法；预览同时列出并替换两侧，不沿用与新分红、新估值无关的旧卖价。
6. 个股与指数走势、经营和分红检查作为风险提示。逐项区分“未通过”和“待补充”，列明指标、日期及缺口，不据此自动暂停加仓，也不要求个股、上证和沪深300全部脱离下跌才恢复。已保存的三档买价直接与有效未复权现价比较；安全边际价仅独立参考，不再作为恢复开关，也不对三档重复打折。默认15%安全边际对应85%估值附近，并非必须跌到75%第三档才算通过。主页面与计划管理均标记各已触发档位及最深触发档位，未取得可靠报价时标记待核实。触价不是成交记录。新价格草案不携带自动暂停指令，保存时保留原手动状态。已有暂停由用户在重新复核后阅读风险和待补充项，自主决定是否预览并确认恢复；不要求所有提示消失。复核不修改价格；报告有效15分钟，预览与确认仍核对选股原则、定价参数及保存计划未变。

原文“PB 偏贵时下调收益率”的方向会提高价格，程序采用更高要求收益率／更低价格约束。高派息、不可持续收益和现金覆盖不足分别处理；金融企业的现金流不套用工业企业口径。

### 非金融企业的现金支持上限

近三年逐年计算每股自由现金流：优先使用该年经营现金流减购建长期资产现金支出，再除以来源所报股本；该接口可能在历史行重复当前股本，因此不能将其称为已核验的历史年末股本。缺少所报股本时，可用该年实际每股分红乘已核实的自由现金流／分红覆盖率折算，并明确标注这个替代依据。总现金流金额不能直接当作每股金额。

税前现金支持上限 = 近三年每股自由现金流最小值 ÷ 1.5。D₁ = min（盈利口径税前分红，现金支持上限）×（1 − 持有期税率）。页面列出三年证据、采用的上限和下调结果。现金覆盖不足 150% 是复核项：以更低可持续分红和更低评估价生成附现金覆盖提示的价格计划；不继续沿用原盈利分红假设，也不只返回文字建议。

若近三年现金流缺失、无法转换为可核实的每股口径，或存在非正自由现金流，则继续阻断网格。正常化盈利非正、三年EPS或五年派息率不足以构成分子、参数无效或全部三锚不可用时也无法计算网格。历史实际派息超过盈利、连续分红待核实、年报陈旧、周期归一盈利待复核、行情缺失或金融专项证据未通过列为独立风险或待补充提示：保留可算出的估值和三档，不自动改变加仓状态。周期归一待复核时明确暂用三年扣非均值；行情缺失时不显示与现价涨跌幅，也不声称当下触价。部分有效三锚仍按第3步计算，不因缺一个比较项丢掉价格。

## 抓取与确认

自动抓取腾讯行情／日月线、东方财富分红、派息日程、财务指标、现金流和国债数据，保留报告期、公告日、价格基准及来源。历史收益率锚使用当时已实施现金分红和未复权收盘价，不能把未来公告倒灌到历史。

腾讯日线和未复权月线主地址失败或返回不可验证数据时，通过腾讯公共代理地址重取一次。月线即使格式正确，若算出的完整月股息率历史太短或过期，也会重取并把请求上限扩至320个月；重复月份不增加样本数。仍失败时保留实际地址、请求／解析错误及尝试次数，同时保留实际取得的最近价格和较完整的历史。自身历史锚必须有至少60个不同月份样本、跨度至少4.8年且最近完整月数据不超过40天，不因抓取失败降低要求；未满足时排除此辅助锚，并列明实际样本数、起止日期和缺口。当前未复权价格与历史完整月样本分别处理。国债依据超过10天、机会成本超过30天时也排除相应辅助锚。

### 金融业自动专项初筛

银行、保险、证券直接解析同一财报主源中的行业专属字段，逐项报告数值、阈值、报告期及同比变化。金融业不显示或套用工业企业的负债率、经营现金流／利润、自由现金流／分红规则。专项初筛未通过与未知项分别显示为风险和待补充，不自动暂停加仓；只要定价分子与三锚依据足够，仍生成可预览写入的网格。可保存价格不表示所有检查均通过。

- 银行：总资本充足率至少12%、核心一级资本充足率至少9%、不良贷款率不超过3%、拨备覆盖率至少150%。这些是本产品的红利初筛参考线，不等于监管合规结论。[《商业银行资本管理办法》](https://www.nfra.gov.cn/cn/view/pages/rulesDetail.html?docId=1134197&itemId=4214)规定的最低资本、储备资本、系统重要性附加资本及第二支柱要求不能合并成对所有银行都适用的一条监管线。本初筛未逐家核验后几项要求。
- 证券：风险覆盖率至少100%、资本杠杆率至少8%、流动性覆盖率及净稳定资金率均至少100%，依据[《证券公司风险控制指标管理办法》第十七条](https://www.csrc.gov.cn/csrc/c106256/c1653957/content.shtml)。结构化指标达到公开最低线不代表已核验全部监管要求。
- 保险：自动核对综合偿付能力至少100%。主源尚未提供核心偿付能力及风险综合评级时，必须具体标明缺少这两项，不能以综合偿付率代替。[《保险公司偿付能力管理规定》第八条](https://www.nfra.gov.cn/cn/view/pages/ItemDetail.html?docId=962016&generaltype=0&itemId=925)要求核心偿付能力至少50%、综合偿付能力至少100%及风险综合评级B类以上同时满足；核心偿付能力或风险综合评级未知不判为整体通过。补充依据应来自该公司的季度偿付能力报告，不能填推测值。

中国平安601318另附2026-10-21已核验的[集团2026半年偿付能力报告摘录](https://group.pingan.com/resource/pingan/IR-Docs/2026/Summary-of-Solvency-Report-of-PAG-for-1H-2026.pdf)：报告期2026-06-30，发布日2026-08-21，PDF第22页核心165.60%、综合198.14%，第24／34页明确集团风险评级尚未开展而不适用。此补充明确标为已核验报告摘录，不称实时抓取；不挪用寿险或产险子公司指标。较新的财报期出现、结构化值与该期不符，或报告超过230天时停止应用。其他保险公司仍须用自身证据，不能继承平安集团“不适用”的结论。原PDF SHA-256为`aae32edfa330a1e206e7f9f91afd55c44cb1360880b55ba3258a7588b7423958`。

专项初筛仅使用截至研究日已经发布的报告，超过230天的行业指标视为过期。它不替代原始财报全文、审计意见或公司特定监管要求的核查。

结构化财务数据与全文财报解读分开标注，无法取得的项目明确列出。选股检查与短期技术节奏分开；缺数据不等于不符合原则。计划移除只处理用户确认且没有持仓的股票，删除时再次核对手工、关联、隐藏、归档及未来已记交易。

模型可读上下文与答案使用具体中文／英文原因，不显示内部原因码。模型给出的网格必须与程序算得的档位一致才能成为价格草案；模型漏给草案或只给买入时，由程序为当前计划中已完成定价的股票补齐精确三档买入与四档卖出。价格草案保留原手动暂停状态，不因下跌加速而丢掉新价格或自动暂停；用户明确要求暂停时才生成暂停草案。缺少关键定价输入时列明缺口，不编造价格。所有价格变更先预览，再确认同时写回买卖两侧；校验新买价与新卖价不交叉。重新计算与生成草案本身不修改已保存的计划。

## 版本规则

功能大更新递增主版本，例如 1.10.0 → 2.0.0；修复递增末位，例如 2.0.0 → 2.0.1。Android versionCode、iOS build number 始终递增。
