# 红利助手的定价与分红口径

2026-11-08按用户确认的审计处理范围更新。本规则替代v4的滚动12个月分红窗口；新网格使用**可计算台账中的最近分红批次÷用户设定的四档股息率**。默认档位沿用经典网格。计算版本为5；旧v5缓存缺少收益率数组且价格行符合经典档位时，仅补回默认档位元数据，不改日期、价格或已保存计划。

这是一套用户选定的现金股息率纪律；5%是中性参考线，不是公允价值。不能为了贴近现价倒推分红或收益率。

## 分红台账与基数

**以东方财富结构化数据为计算基准，不再主动请求巨潮或下载、解析新PDF**。逐笔保留所属报告期、分红类型、公告日、登记日、除息日、每10股派现、送转比例及来源。基数“已核验”表示频率、最近所需批次、现金及股本归一资料足以计算，不表示每个辅助字段都完整或已与官方PDF交叉核对。登记日缺失、登记日与除息日关系异常等元数据问题保留为观察，不阻断可计算基数；现金金额、必要送转未知或真实来源冲突仍不能参与计算。旧版本缓存的PDF证据可保留并合并，原核验日期不改，不虚报本轮巨潮请求成功。

每股分红以每10股派现÷10计算，并按截至观察日已生效的送转统一至当前股本。同日送转也计入调整。每批只计一次；同一报告期来源日期冲突不能伪装成第二批。不得倒灌未来公告或未来送转。

先从历史判断频率：稳定半年分红取最近两个不同的已实施批次，年度分红取最近一个；近期曾有中期分红但最新两笔常规分红不是相邻半年所属期，不能把两个年度相加；频率无法确认、所需批次不足或最新所需批次存在冲突时不能退回更早旧批次凑足金额。已公告未实施预案单独列作前瞻参考，不进基数；取消和明确不分红不是预案。

基数与可比年报每股收益×派息率的偏离率仅作观察，**不再以超过25%作为阻断或新价格失效条件**。缺少可比盈利或派息率时注明待补，不将未知写成已通过。该盈利参考不能替代实际现金分红，也不因偏离而改写基数。

历史公告核验的 PDF 缓存（SHA-256 与原核验日期）保留为可选附加证据；2026-11-07 起研究流程不再主动下载 PDF。网络失败保留已有证据，不能把旧台账重新标成当天已核验。

自动补齐仍缺少当前定价所需资料时，可以打开补录表单。已有字段预填，保留最近已实施批次、每10股派现、报告期、实施日期、送转及来源；0必须明确填写，不能把空值当作无送转。半年分红取相邻两期，年度分红取最近一期。存在来源冲突时须明确确认；盈利和派息交叉校验资料为辅助观察，不要求为了消除偏离而补成一致数值，不得只输入总分红绕过真实来源冲突。

补录与自动资料分开保存，方案和已保存网格明确标记“用户确认资料”及原确认日期，范围确认最长30天；来源变化或范围确认过期后不继续提升为当前依据。自动资料已可生成时优先使用自动结果。补录数据随JSON与Excel备份恢复；保存资料只重新计算，价格在原卡片显示一次，点击该卡片的确认写入后才更新四买四卖。

## 税率、价格与确认

默认按持股1个月至1年、税率10%计算；可选不满1个月20%、满1年0%。界面同时显示税前和税后两列；当前选择的税后列用于保存计划，税只扣一次。这是用户选择的持有期假设，非根据每笔交易自动核税。

| 用途 | 股息率 | 取整与份额 |
| --- | --- | --- |
| 买入默认 | 5.5%、5.75%、6%、6.5% | 向下取整到分，各25% |
| 中性参考 | 5% | 只作纪律参照 |
| 卖出默认 | 4.8%、4.5%、4.2%、4% | 向上取整到分，各25% |

买入收益率按档位递增，卖出收益率递减，各为四档；输入单位为百分数，保存单位为基点。两侧使用相同税后基数，没有额外安全边际折价，不以历史分位、PB或国债等自动改档。买入价是上限；达到价格条件不是成交记录。预算、持仓、整手、累计仓位及手动暂停仍用于执行计划。

平安银行真实公告核验示例：2025年度每10股3.60元、2026中期每10股2.49元，税前基数0.609元／股；默认10%税后0.5481元／股。买档9.96／9.53／9.13／8.43元，卖档11.42／12.18／13.05／13.71元。税率0%时卖档12.69／13.54／14.50／15.23元。示例说明金额与取整，不代表当前报价或交易建议。

来源：[2025年度实施公告](https://static.cninfo.com.cn/finalpage/2026-06-05/1225352449.PDF)、[2026中期实施公告](https://static.cninfo.com.cn/finalpage/2026-09-17/1225568476.PDF)。招商银行年度公告中本次派息与全年累计分红分别解析，不能把两者混为本批金额。

网格价格只在当前价格卡片展示一次，**不再打开独立预览或重复展示第二套网格**。用户点击卡片内“确认写入网格计划”后，同时更新四买四卖；内部仍在写入前读取已保存计划并核对状态指纹、当日研究、证据批次及参数，跨日或变化后须重新检查。保存生成时间、税前基数、税率、参数版本、基数口径与价格行中的实际收益率。模型来源元数据由确定性代码重建。不得改预算、持仓或手动暂停。

## 已保存网格与三态

每次选股检查重新计算基数。比保存时变化超过10%、生成后发生除息／送转、税率、参数版本或买卖档位收益率改变时提示重新生成；不自动替换。实际收益率已随价格行保存，旧来源不伪造新字段。没有生成来源的历史网格保留为旧网格。手工修改价格会清除旧生成依据，修改预算或份额不会清除。JSON、Excel继续往返保存来源。

| 数据和计划 | 展示 |
| --- | --- |
| 当前基数核验完整、来源一致且保存依据有效 | 触发／未触发 |
| 当前基数缺失、冲突或依据过期，但有显式保存网格 | 按已保存网格：触发／未触发（基数未核对） |
| 没有已保存显式网格，且新基数无法核验 | 无法判断 |

首页读取已有台账和检查缓存，不在渲染时下载公告，也不给旧证据改日期。现价高于全部卖档，或比最低买档低至少20%，提示网格偏离市场区间。股票与基金使用同一行情判断：**交易日要求报价日期为当天；仅非交易日允许36小时内抓取的有效报价**。抓取时间不能在未来，原始报价仍须通过日期、时间、金额及不超过10天等检查；非交易日也不代表已确认可执行交易。周末和已维护的交易所休市日按非交易日处理；当前维护2025、2026年，其他年份的未知工作日不套用旧报价例外。新草案的现价比较还要求报价不早于最近除息／送转。

交易所休市依据：[2025年通知](https://www.sse.com.cn/disclosure/announcement/general/c/c_20241223_10767108.shtml)、[2026年通知](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)。调休上班的周六、周日仍休市。

## 历史、财务与展示

历史股息率逐个完整月使用当时可知的结构化分红、最近批次和股本口径。原始价格月份与资料可计算的有效月份分开列示。有效比较仍要求至少60个不同完整月、跨度4.8年、最新月不超过40天；缺现金、送转未知、真实冲突、月份不足及过期分别记录。历史与财务比较为一般关注，不阻断当前可计算的网格。

ROE保留财报原值：年报用年报值；季度累计ROE按12÷已报告月数年化展示并标口径，旧季度缓存无年化依据时显示待核实。年度筛选不用季度值冒充年报。新增默认营收与利润同比门槛0%，已保存的用户阈值保持不变。

银行保留资本充足率、不良率、拨备覆盖率，并加入关注类贷款占比、90天以上逾期贷款／不良贷款偏离度、净息差及内生资本支持：ROE×(1−派息率)与风险加权资产同比增长比较。净息差观察同比变化，不捏造统一安全阈值。总逾期不能冒充90天以上逾期。缺少专门披露字段就具体标未知，支持带报告期、发布与核验日期、原文来源的银行补充证据。资本支持比较是可比指标下的简化检查，不等于监管资本预测。

现金股息率的报告期显示所选分红批次所属期；行情日期另列，不用今天日期代替财务报告期。经营、金融专项、现金流及趋势是复核资料，不自动暂停或改变网格。

现金股息率检查从有效未复权价格和对应可计算分红基数重算，不复用无日期、无依据的旧股息率缓存。分红下载失败、必要现金或送转资料不足、真实冲突、人工确认范围过期等仍须保留实际缺口；辅助字段与盈利交叉校验偏离不再构成自动阻断。

一般关注（包括筛选指标风险或未知、财报新鲜度、财务与趋势观察等）不限制买入，也不自动改价或暂停。筛选结论保留原通过／未通过／未知，操作条件不再仅因该结论受限。必要定价或行情资料缺失、保存网格失效、未分配预算、持仓与整手限制、手动暂停及交易会话未确认等，仍按各自条件处理。

红利首页同时展示股票和基金计划、金额和触发情况；可直接生成今日操作建议，聊天中的提问入口保留。选股检查突出网格，其余资料集中在一个展开区，台账内不再嵌套目录。

基金卡片直接展示三档买入网格价格：第1档沿用原引擎的基准高点×(1−回撤阈值)，第2档为第1档×90%，第3档为第2档×95%，逐档以整数微元四舍五入。第2、3档仅为后续网格参考，不改变当前单一入场触发、预算、持仓或卖出规则；卡片不再展示“依据与数据”长文。

红利首页最新单期公告分红与未来持有一年预测仍各自独立：中期不乘二，未披露不编造，去年同期估算标明原期，今天已除息的事件不计作新持有者可领取。它们不替代最近批次网格基数。

## 发布验证

2026-11-04 的8.0.1公告解析验证属于历史记录。当前显式检查使用结构化分红资料，不再主动补查巨潮PDF；旧证据日期保留，旧价不自动覆盖。价格说明采用“最近已实施分红批次 → 扣税一次 → 除以设定股息率”，观察与来源按需展开；确认写入沿用当前卡片，不重复展示网格。

股票预算可显式预览并均分全部已保存股票，原 0% 和隐藏股票也参与；确认时核对总预算、股票名单和原权重。删除且选择再分配时，只将释放比例平均加给全部剩余股票，原未分配比例继续保留。股票和基金预算独立，不改变持仓、价格或手动暂停状态。

正式版本按项目约定递增；本次方法更新使用5.0.0，Android versionCode与iOS build number延续递增。测试、构建、公告真实抓取、签名发行及设备安装分别报告。计算版本更新不代表已发布或已通过真机验证。
