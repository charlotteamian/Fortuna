# Fortuna 3.0.0 价格监控验证

日期：2026-10-22。Android versionCode / iOS build：29。

监控计划独立于账户持仓数量保存。股票/ETF、黄金共用目标价、方向、用户指定百分比范围；接近按设备本地日去重，达到或越过目标自动结束，最终提醒保留到关闭。停止、修改或删除后的旧异步响应不能改写新计划。

验证包括整数价格及范围边界、跨日和同日升级、清仓/无持仓、网络失败与旧缓存、部分行情失败、市场币种、来源日期、北交所920和美股带点代码、黄金汇率失败隔离、JSON/Excel全量恢复与旧版备份兼容。

此版本使用 App 内横幅。启动、回前台与打开期间每日检查，手动刷新及持仓价格刷新也检查；没有新增系统后台轮询或通知权限。黄金沿用全球现货换算至账户币种/克的报价口径。

浏览器交互、自动测试、正式签名与更新检测、模拟器覆盖安装的实际结果另存本目录。实体设备安装与关闭 App 后的后台通知不属于已验证能力。

- 392 项 Node 测试通过，ESLint、TypeScript、生产构建及差异检查通过；Android/iOS 资源已同步，iOS 3.0.0/build29 与45个网页资源校验通过。
- 隔离 Chrome 浏览器使用合成清仓账本、拦截的带日期行情，验证分类入口、清仓持仓选择、提醒范围必填、接近横幅、同日关闭不重弹、到价结束、停止重启、黄金按克及重载保留；390/320px无横向溢出，无页面异常。
- 浏览器测试验证交互与确定性触发，不等同于真实行情服务准确度或实体机验证。
