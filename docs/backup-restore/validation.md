# Fortuna 1.8.2 备份恢复验证

日期：2026-10-14。Android versionCode：18；iOS build：18。

## 恢复行为

- 存在账户、记录、持仓、交易、产品、资产配置或红利工作台数据时，选择文件后显示「已有数据，是否全部覆盖？」。
- 「是」在一笔 Dexie 事务中清空全部备份表，再写入完整备份。相同 ID 对应的数据会替换，备份中没有的旧项目会删除；不会叠加行。
- 「否」不会修改任何备份表。校验失败不进入写入事务；写入失败会整批回滚。
- 旧备份缺少设置时使用与新安装相同的默认设置，清空旧配置及汇率缓存。
- 文件读取、工作表校验和数据库写入错误分别显示，错误信息保留在弹窗中，关闭弹窗后也可查看。

## 复现与修复

旧导出逻辑逐表读取。在读取账户之后并发创建账户及记录，会把新记录写入导出文件，却缺少对应新账户；导出文件随后恢复失败。新增回归测试在修复前失败，改用跨全部备份表的只读事务后通过。JSON 与 Excel 导出共用该快照读取。

正常完整备份在原 1.8.1 的网页和 Android 模拟器中也能恢复，没有证据将特定手机的原报错归因于已有 ID 冲突。1.8.2 明确落实完整覆盖，并保留具体失败信息以便定位设备差异。
