# Fortuna 7.0.0 验证

基于已发布 v6.0.1，在独立工作区实现。未操作真实用户数据库；其他工作区的更新器草稿保持原样。

合并选股与计划后，既有研究缓存、无研究缓存、隐藏金额、修改状态、暂停买入、二次确认删除与有持仓禁止删除均保持可用。未达标优先展示具体规则及数值，行情未知继续保留未知，完整依据与定价方案按需展开。基金入口/退出规则与股票定价算法未改变。

首页使用既有 Account.sortOrder 保存分类和账户顺序，不修改余额或账户业务字段。证券和黄金监控一起显示于首页顶部。

本地 833 项测试、16 项 Android 单测、lint、生产构建、Android/iOS 同步、iOS 版本与48个资源核验通过。隔离浏览器合计23项检查、16组320/390px与1.3倍字体布局通过，pageerror=0。脚本和明细见本目录及 ../home-assets-700/。

浏览器后台事件为模拟。签名APK、GitHub Actions、更新识别和Android模拟器核验结果在发布后追加。真实手机升级/数据保留、真实行情与真实模型仍未验收。
