# Fortuna 8.0.0 验证

基于当前 main 的 fdea100，在 codex/release-8.0.0 开发；未修改真实用户数据库或其他工作区。Android versionCode 44，iOS 元数据 build 44。

基金首页采用统一检查事实直接展示今日操作。选股工具栏、股票标题、目标、价格表及放大字体排版已修整；来源统一折叠入口，普通主依据从约 2752px 降至 1165px。

原定价方法与数值规则保持不变。修复同日失败公告被缓存跳过，以及历史公告字段缺口令后续有界核验过早停止的问题。显式补齐最多推进 3 个每批 12 份公告的批次；列表/下载失败或耗时过长即停止，旧证据原日期不变。所需最近批次、股本调整、完整来源和交叉核验继续决定新价可用性；不以历史字段缺口伪造当前已通过。移除资料不足时的备用价格和直接应用入口，新价继续预览后确认。

一键重新分配预览均分全部股票，包括 0% 和隐藏股票；预算、名单或权重变化拒绝旧预览。删除且再分配只均分释放比例，包含原 0%，保留原未分配。持仓、价格、暂停状态和独立基金预算未被预算操作改写。

854 项自动测试、lint、生产构建、16 项 Android 单元测试及 iOS 48 个资源核验通过。隔离 Chrome 12 项功能场景、23 项布局检查通过（320/390px、1/1.3 倍字体和桌面），全部 10 个证据目录展开仍无溢出、重叠或裸翻译键，页面错误 0。基金另有 8 组深浅主题/字号/宽度矩阵和金额隐藏验证。详见本目录 JSON 与脚本。

平安银行一次真实服务核验：近期中期与年度两个批次分别为每10股2.49元、3.60元，税前0.609元/股、10%税后0.5481元/股；四买9.96/9.53/9.13/8.43元，四卖11.42/12.18/13.05/13.71元，整数税与取整检查通过，来源和原日期已记录。历史不支持的公告字段仍保留缺口；未保存任何价格计划。该单股服务检查不等于全部标的或其他网络下服务质量验收。初次浏览器检查被同步中的 Vite 重载打断，随后空白页测试环境产生开发客户端错误；最终正常独立 App 页面检查成功、pageerror=0，详见 live-service-smoke.json 的说明。

签名 APK、GitHub Release 和更新器验证结果在发布后记录。未进行真实手机安装、升级数据保留或真实 AI 模型验证。
