## 解释层边界

价格、资格、触价、操作状态和可确认动作由本地代码单独决定。模型没有动作/草案理由输出接口，也不能借解释正文替换这些结果。明确的重算/暂停请求先由本地检查生成预览，模型未配置也可用；解释为什么暂停不会生成暂停草案。

模型解释只在需要时请求，正常概念和追问允许自由措辞，不再被有限概念表无条件替换。已有16组本地说明继续直接可用，没有新增词条代替问答；本地教学算式使用明确假设并重新计算。指定每股分红0.8元、股价20元时返回4%，缺输入保持缺失，不偷偷改用默认数字。

需要AI时，本地结果先通过回调显示。结构化解释只接受概念、已有依据引用和假设算式三类内容；拒绝额外字段、动作/理由字段、未知引用、正文伪造数字和来源。实际数值、日期和链接由本地依据引用呈现，教学例子明确与真实证券资料分开。风险说明还需引用相关事实，逐句解释条件、前提或比较限制；不能用真实引用放行“资料齐备、条件具备”的无条件结论。任何一段不通过时整份模型解释不展示，保留本地结果，而不是在错误结论后追加警告。

这不是对任意自然语言真实、安全的数学证明。叙述筛查是额外防线，保守语法可能拒绝本来合理的措辞；系统会明确提示解释未采用，允许再问，不能把拒绝伪装成解释成功。模型未配置、网络错误、HTTP失败和超时都保留本地说明/依据及检查。没有测试真实提供商质量。

## 资料与动作隔离

聊天使用新的只读上下文加载：不初始化设置、不种入默认股票、不下载资料、不刷新或修复缓存。已有证据日期不变。当前研究卡的讨论资料仅作为内存里的 `explanationResearch`，以单独的 `discussion:*` 引用保留原时点、报告期和来源；不会覆盖当前执行检查。候选股即使不在计划中也能讨论，但不会因此产生持仓、计划或确认动作。

只读服务/说明/预览不写账本。聊天仍按原流程保存模拟会话；未把“保存会话”误称为全流程零写入。教学计算不是新的定价引擎，也不用于生成真实档位。
