# Fortuna 红利阶段2计划（尚未实施）

阶段1.2验收后再启动。本计划仅调整阅读层级、列表和折叠；不改价格、资格、触价、操作状态、基金条件或解释层权限。

## 目标与呈现

股票与基金收起后都能迅速看清计划和约束。每项保留名称/代码、现价及来源时间、下一买/卖目标与主要约束；最多三条主要原因。金额继续独立默认显示，未知持仓与确认零持仓分开。

| 页面状态 | 呈现 |
| --- | --- |
| 默认收起 | 紧凑概要；名称、金额、当前价格/时间、下一档、买卖状态及主要约束直接可见 |
| 展开计划 | 才展示完整四买四卖或基金入场/退出详情；收起时表格确实隐藏 |
| 查看依据 | 一个依据入口，收纳经营、分红台账、财报、技术和来源；避免多层目录 |
| 预览价格 | 保留现有唯一预览入口及确认校验；预览不写入，确认同时更新两侧 |

下一档直接读取阶段1.1的原档号和累计目标状态。`price_reference/unknown`只显示带说明的价格参考，不展示虚构股数或操作资格；`covered/no_holding/below_lot`分别呈现。暂停不改变触价事实。

## 实施顺序

1. 在隔离样本中记录当前首页和选股页的收起/展开高度，固定10只股票、2只基金及同一视口、字号、报价和持仓。
2. 调整首页股票/基金概要及实际折叠，再调整选股检查的概要和单个依据入口；沿用共享摘要，不创建另一套状态或计算。
3. 补充能直接定位“持有、手动暂停、到价、资料未知”的筛选；筛选只影响阅读，不写计划或状态。
4. 检查已有折叠偏好的读取和恢复。若需要修复Excel偏好往返，作为单独兼容项明确列出和验证；不顺带迁移账本、改数据库或备份结构。
5. 完成正反回归、手机尺寸验证及前后测量，交付本地可回退提交后停止。

预计涉及 `DividendPage`、`DividendHomePlan`、`DividendFundHomePlan`、`DividendCheckStatus` 与选股工作区的展示/CSS；服务层仅复用现有摘要。以实际依赖为准，不承诺先重写全部组件。

## 验收

- 用同一组10股票2基金，逐项报告收起前后总高度和可见项数，并提供全页截图。目标明显减少滚动，不靠减小字号、隐藏金额或省略关键约束达成。
- 320/390px、1×/1.3×字号无横向溢出；键盘/触控均能展开收起，焦点和展开状态明确。
- 四买四卖、金额、原档号、持仓与人工暂停保持；已持有/零持有/未知基金在首页、管理页、AI入口一致。
- 模型配置或失败不影响本地结果；解释和追问继续有效，模型不能改变动作、条件或草案理由。
- 复跑现有全量test/lint/build、只读零写入、价格预览、旧编辑器冲突/草稿/行情合并及必要浏览器入口。没有真实接口或真机证据时继续明确标注模拟范围。

## 不包含的工作

完整无AI今日清单、全流程取消/硬超时和单项重试仍属于阶段3。特别分红如何纳入、缺交叉证据是否阻断新计划、证据快照持久化继续单列待决。阶段2不改这些业务规则，也不推送、安装或发布，除非之后另有明确要求。
