## 状态的含义与安全边界

`dividendCheckSummary` 只整理既有计算结果：

| 区块 | 输出 |
| --- | --- |
| eligibility | pass / fail / unknown；基于用户原则、可用证据和研究时间，最多三条主要原因；不按风险数量评分 |
| grid | verified / saved_unverified / unavailable；明确saved / current / none来源，税前税后、所用税率、版本、来源和缺口；保存执行价与本次草案分开 |
| trigger | triggered / not_triggered / unknown；按源时点确认今日观察；历史可用比较单列；partial网格保留原档号，不虚构累计股数 |
| risk | blocking / attention / evidenceInsufficient；附来源、已知报告/发布/核验日期、影响和重试/人工处理。现金公告核验日不会冒充财报核验日 |
| actionCheck | blocked / review / wait / confirmation_candidate / unknown；买卖独立，买入原则失败不自动禁止卖出；所有确认候选仍需人工确认 |
| freshness | 研究生成、实际报价、下载、财报期、发布日和原核验日分别保留，另有语义指纹 |

新模型调用原 `dividendPricingPlan`、`reviewDividendGrid`、`buildDividendHomePlan`、`dividendResearchAdvice` 和基金引擎。价格比较与状态映射在摘要集中完成，没有第二套分红计算公式。旧兼容工具没有从存储中删除，但其推算价格不再进入当前展示/AI/恢复检查的价格来源。

摘要里的grid.sourceUrls/selectedBatchIds是当前复核依据，不能当作已保存网格的原始生成快照；原始快照缺失会单独标记，不能倒填。

没有交易日历、停牌或券商可成交证明时，当日合法报价可表示**观察到价**，操作状态仍需复核；不能把下载成功或工作日推断成已经可以成交。一般技术、历史分位、国债等参考资料不会改价格或写入暂停；不涉及用户必要原则的比较缺口仅作信息。

只读加载还验证了未初始化settings时不会为检查创建或迁移数据。模型、加载、展示、确认校验不会自动修改网格、预算、持仓或手动暂停。用户明确点击现有保存/确认按钮的功能仍保留，本次只在隔离模拟库操作这些按钮。

## 尚未解决和刻意保留的边界

1. 四项暂定规则仍需用户后续决策：特别分红纳入、缺交叉证据的生成门槛、自动禁买、证据快照持久化。现阶段只展示影响和复核限制。
2. 未接交易日历、券商可用现金/费用/流动性与完整停牌信息，因此不会宣称已满足实际成交条件。
3. 最后失败的临时视图存于进程；已完成失败研究可沿用现有研究缓存保留影响。若失败后既未完成缓存保存又直接重启，只能读到上一次成功资料，无法凭现有字段恢复这次未记录失败。新请求仍会重新核验；未为此增加schema。
4. 无版本字段时，编辑指纹不能识别“删除后逐字段完全相同重建”的ABA情况；任何已识别字段差异或记录不存在都会冲突。真实账本版本字段未新增。
5. 银行专门原文补证的完整自动抓取、无AI的一键今日清单、全流程取消/硬超时及单项重试界面仍属后续范围。已有检查状态可独立于AI显示；今日建议入口的完整流程本阶段没有重做。
6. 首页冗长和折叠后仍保留表格的结构原样保留，属于阶段2；本阶段没有用隐藏证据换取更短页面。
